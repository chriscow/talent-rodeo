Your goal is to analyze this transcript and create a steering query that accurately represents the user's job search preferences. The steering query should be structured as follows:

1. Query: The main job title or skill we will search on
2. MoveToward: A concept to move results toward (optional)
3. MoveAway: A concept to move results away from (optional)

To complete this task, follow these steps:

1. Carefully read and analyze the provided transcript.

2. Identify the main search query:
   - Look for the AI assistant's suggested search query and any corrections or additions made by the user.
   - If the user agrees with the suggestion, use that as the main Query.
   - If the user corrects or modifies the suggestion, use the corrected version as the main Query.
   - If the user proposes multiple suggestions, determine between the AI's suggested search query and the user's suggestions to select one as the main search query. Incorporate the rest into the MoveToward concept below.
   - Use the canonical form for the terms of the search query (i.e. "Go (Golang)" instead of "Go").

3. Determine the MoveToward concept:
   - Identify additional search terms or preferences mentioned by the user.
   - Look for positive aspects of jobs that the user expresses interest in.
   - Combine these elements into a concise sentence that represents what the user wants to move toward in their job search.

4. Determine the MoveAway concept:
   - Look for specific mentions of things the user wants to avoid in their job search.
   - Combine these elements into a concise sentence that represents what the user wants to move away from in their job search.

5. Create the Reranking Query
   - Combine Query, MoveToward concept and MoveAway concept into a concise query in sentence form to use for a reranking transformer to rerank the results.

6. Formulate your reasoning:
   - For each component of the steering query, provide the actual quotes from the transcript that support your decisions.
   - Explain your rationale for the chosen ForceToward and ForceAway values.

7. Create the final JSON output:
   - Structure the steering query as a JSON object that can be unmarshaled into the provided Go struct.
   - Ensure all fields are properly formatted and values are appropriate types (string for Query, MoveToward, and MoveAway; float64 for ForceToward and ForceAway).

Your final output should be a JSON object containing only the steering query components, structured as follows:

<answer>
{
  "Query": "Main search term",
  "MoveToward": "Sentence describing what semantic concepts to move toward",
  "MoveAway": "Sentence describing what semantic concepts to move away from",
  "RerankingQuery": "All encompasing sentence that combines the concepts of Query, MoveToward and MoveAway"
}
</answer>

Remember to base all components of the steering query on actual statements made by the user in the transcript.
