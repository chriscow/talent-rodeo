### Example for Stage 1: Introduction and Rapport Building  

**Goals**:  
- Establish trust and rapport with the candidate.  
- Explain the purpose and structure of the call.  
- Confirm basic contact details and current employment status.  

**Subgoals**:  
1. Create a friendly opening to make the candidate comfortable.  
2. Provide an overview of the conversation stages.  
3. Confirm or update personal and professional details (e.g., current role, location).  

**Example Questions**:  
- "Thank you for sharing your resume! Can you confirm your current role and what you're focusing on professionally right now?"  
- "What inspired you to explore new job opportunities?"  
- "Is there anything you’d like to add or clarify before we dive in?"

**Success Criteria (JSON Schema)**:  
```json
{
  "type": "object",
  "properties": {
    "contactConfirmed": { "type": "boolean" },
    "currentRoleValidated": { "type": "boolean" },
    "candidateComfortable": { "type": "boolean" }
  },
  "required": ["contactConfirmed", "currentRoleValidated", "candidateComfortable"]
}
```

### Example for Stage 2: Skills and Technical Expertise  

**Goals**:  
- Validate the candidate's technical skills and expertise as outlined in the resume.  
- Identify additional technical proficiencies or areas for growth.

**Subgoals**:  
1. Confirm key skills mentioned in the resume.  
2. Explore technical projects or responsibilities not listed.  
3. Uncover their proficiency levels with critical tools and technologies.

**Example Questions**:  
- "You mentioned experience with Python and Go. Can you describe your most recent projects using these languages?"  
- "Are there any tools or technologies you’ve worked with recently that aren’t on your resume?"  
- "What areas of your technical skill set are you most eager to improve?"

**Success Criteria (JSON Schema)**:  
```json
{
  "type": "object",
  "properties": {
    "keySkillsValidated": { "type": "boolean" },
    "additionalSkillsIdentified": { "type": "boolean" },
    "growthAreasDiscussed": { "type": "boolean" }
  },
  "required": ["keySkillsValidated", "additionalSkillsIdentified", "growthAreasDiscussed"]
}
```
