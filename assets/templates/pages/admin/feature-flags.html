System Feature Flags & Scheduling

Search Scheduler

Controls whether the search scheduler processes search criteria automatically

Note: Set both start and end hour to 00:00 to run 24/7. Time window can cross midnight (e.g., 17:00-00:00).

Subscription Processor

Controls whether the subscription processor publishes job matches to users

Note: Set both start and end hour to 00:00 to run 24/7. Time window can cross midnight (e.g., 17:00-00:00).

ScrapingDog Workers

Controls whether ScrapingDog workers process job search requests from the queue

Feedback Processor

Controls whether the feedback processor analyzes user feedback and updates steering queries

Note: Set both start and end hour to 00:00 to run 24/7. Time window can cross midnight (e.g., 17:00-00:00).
