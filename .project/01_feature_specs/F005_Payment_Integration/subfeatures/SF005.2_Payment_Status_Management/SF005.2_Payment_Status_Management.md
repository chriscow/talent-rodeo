# SF005.2: Payment Status Management

## Overview
This subfeature implements tracking of payment status and access periods to ensure users receive premium features based on their payment status. For the MVP, we'll use a simple approach focusing on the subscription_end_date field to determine access status for one-time payments.

## User Stories
- As a candidate, I want to see my current premium status and expiration date in my profile
- As a candidate, I want to receive a confirmation when my payment is processed
- As an administrator, I want to see payment statuses for all users
- As the system, I want to automatically update user permissions based on payment status

## Requirements

### Payment Status Tracking
- Use subscription_end_date in the candidates table to determine premium access
- Record basic payment information in a payments table for record-keeping
- Define clear binary status (has premium access / no premium access)
- Provide APIs for other parts of the system to check payment status
- Update subscription_end_date when one-time payment is successful via webhook

### User Permission Management
- Define premium features that require payment (more job searches, daily searching, email notifications)
- Create permission checks based on subscription_end_date
- Update user access rights when payment is processed
- Automatically revert to free tier when subscription_end_date is reached

### Payment Receipts
- Use Stripe's built-in receipt emails for successful payments
- Store basic payment records for administrative purposes
- Display payment confirmation in the application after successful payment

### Admin Dashboard (Future Enhancement)
- Display payment status for all users
- Show payment history and details
- Provide basic payment statistics

### Access Control Implementation
```go
// Example middleware for checking premium access
func RequirePremiumAccess(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        candidateID := GetCandidateIDFromContext(r.Context())
        
        // Query the database to check subscription_end_date
        var hasPremiumAccess bool
        err := db.QueryRowContext(r.Context(), 
            "SELECT subscription_end_date > NOW() FROM candidates WHERE id = $1", 
            candidateID).Scan(&hasPremiumAccess)
            
        if err != nil || !hasPremiumAccess {
            // Redirect to upgrade page or show error
            http.Redirect(w, r, "/upgrade", http.StatusSeeOther)
            return
        }
        
        next.ServeHTTP(w, r)
    })
}
```

## One-Time Payment Flow
1. User initiates one-time payment through Stripe Checkout
2. Upon successful payment, Stripe sends webhook notification
3. System processes webhook, recording payment and updating subscription_end_date to 30 days from now
4. User now has access to premium features until subscription_end_date
