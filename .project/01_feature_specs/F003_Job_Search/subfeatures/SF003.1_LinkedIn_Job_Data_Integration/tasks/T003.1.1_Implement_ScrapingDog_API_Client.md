# T003.1.1: Implement ScrapingDog API Client

## Description
Create a dedicated API client for interacting with the ScrapingDog service to fetch LinkedIn job listings. The client should handle authentication, request formatting, response parsing, rate limiting, and error handling.

## Implementation Details

### Client Structure
- Create a client package in `internal/api/scrapingdog`
- Implement a client struct with configurable options:
  - API key
  - Base URL
  - Timeout settings
  - Retry configuration
  - Rate limit handling

### API Methods
- Implement job search functionality:
  - Support for keyword-based searching
  - Location filtering
  - Pagination support
  - Job type filtering
  - Experience level filtering
- Create standardized response structures for job listings
- Implement request/response logging for debugging

### Error Handling
- Implement specific error types for different failure modes:
  - Authentication errors
  - Rate limiting errors
  - Network errors
  - Parsing errors
- Add context to errors for better debugging
- Implement retry logic for transient failures

### Testing Framework
- Create unit tests with mocked HTTP responses
- Add integration tests with configuration for real API usage
- Document test setup and required credentials

### Sample Implementation
```go
package scrapingdog

import (
	"context"
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"time"
)

// Client provides methods to interact with the ScrapingDog API
type Client struct {
	httpClient *http.Client
	apiKey     string
	baseURL    string
}

// NewClient creates a new ScrapingDog API client
func NewClient(apiKey string, options ...Option) *Client {
	client := &Client{
		httpClient: &http.Client{
			Timeout: 10 * time.Second,
		},
		apiKey:  apiKey,
		baseURL: "https://api.scrapingdog.com/v1",
	}
	
	// Apply options
	for _, option := range options {
		option(client)
	}
	
	return client
}

// JobSearchParams contains parameters for job search requests
type JobSearchParams struct {
	Keywords     string
	Location     string
	JobType      string
	ExperienceLevel string
	Page         int
	PageSize     int
}

// SearchJobs performs a job search using the provided parameters
func (c *Client) SearchJobs(ctx context.Context, params *JobSearchParams) (*JobSearchResults, error) {
	// Construct request URL with query parameters
	endpoint := "/linkedin/jobs"
	u, err := url.Parse(c.baseURL + endpoint)
	if err != nil {
		return nil, fmt.Errorf("invalid URL: %w", err)
	}
	
	q := u.Query()
	q.Set("api_key", c.apiKey)
	q.Set("keywords", params.Keywords)
	
	if params.Location != "" {
		q.Set("location", params.Location)
	}
	
	// Add additional parameters
	// ...
	
	u.RawQuery = q.Encode()
	
	// Create request
	req, err := http.NewRequestWithContext(ctx, "GET", u.String(), nil)
	if err != nil {
		return nil, fmt.Errorf("failed to create request: %w", err)
	}
	
	// Execute request
	resp, err := c.httpClient.Do(req)
	if err != nil {
		return nil, fmt.Errorf("request failed: %w", err)
	}
	defer resp.Body.Close()
	
	// Handle non-200 responses
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("API returned non-200 status: %d", resp.StatusCode)
	}
	
	// Parse response
	var results JobSearchResults
	if err := json.NewDecoder(resp.Body).Decode(&results); err != nil {
		return nil, fmt.Errorf("failed to parse response: %w", err)
	}
	
	return &results, nil
}
```
