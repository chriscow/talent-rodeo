# T004.5.2: Match Indicators

## Task Description
Design and implement visual indicators for match quality that clearly communicate how well a job aligns with a candidate's skills and preferences. These indicators should be intuitive, visually appealing, and immediately convey the relative strength of a match.

## Acceptance Criteria
1. A match percentage indicator is displayed prominently on each job card
2. The indicator visually represents the match percentage (0-100%)
3. Different match quality levels are distinguished by color coding:
   - Excellent matches (80-100%): Green
   - Good matches (60-79%): Light green
   - Moderate matches (40-59%): Yellow
   - Fair matches (30-39%): Orange
4. The indicator is accessible (meets WCAG contrast requirements)
5. Both numeric percentage and visual representation are included
6. The indicators render correctly across all supported browsers

4. Add a helper function for determining match tiers in `/cmd/web/templates.go`:
   ```go
   // Update the template functions
   functions := template.FuncMap{
       // Existing functions
       
       "matchTier": func(percentage int) string {
           switch {
           case percentage >= 80:
               return "excellent"
           case percentage >= 60:
               return "good"
           case percentage >= 40:
               return "moderate"
           case percentage >= 30:
               return "fair"
           default:
               return "poor"
           }
       },
   }
   ```

## Technical Notes
- The color coding follows accessibility guidelines for contrast ratios
- The circular indicator provides a quick visual reference
- The progress bar gives additional context about the match quality
- The hover state provides a tooltip explaining the match indicator
- Consider adding animated transitions when cards are first displayed
- The indicator remains visible on mobile but is repositioned for better layout
