# T004.5.1: Card Component Design

## Task Description
Design and implement the job card component that will be used to display job matches to users. This task includes creating the HTML structure, CSS styling, and layout for job cards that effectively present essential job information in an intuitive format.

## Acceptance Criteria
1. A reusable job card component is implemented with all required elements:
   - Job title
   - Company name
   - Company logo (with default fallback)
   - Location (city or "Remote")
   - Brief job description
   - LLM match explanation
   - User interaction buttons
2. The card has a clean, modern design that aligns with the application's style guide
3. The layout is responsive and works well on both desktop and mobile devices
4. The component accommodates different content lengths without breaking the layout
5. Visual hierarchy emphasizes the most important information
6. The design includes appropriate spacing, typography, and color usage

3. Add helper functions for template rendering in `/cmd/web/templates.go`:
   ```go
   // Register custom template functions
   func newTemplateCache() (map[string]*template.Template, error) {
       // Existing code
       
       // Add custom functions
       functions := template.FuncMap{
           "truncate": func(s string, n int) string {
               if len(s) <= n {
                   return s
               }
               return s[:n-3] + "..."
           },
           "split": strings.Split,
           "firstChar": func(s string) string {
               if s == "" {
                   return ""
               }
               return strings.ToUpper(string(s[0]))
           },
           "nl2br": func(s string) template.HTML {
               return template.HTML(strings.Replace(
                   template.HTMLEscapeString(s), 
                   "\n", 
                   "<br>", 
                   -1,
               ))
           },
       }
       
       // Use the functions in your template parsing
       templates = template.New("").Funcs(functions)
       
       // Rest of existing code
   }
   ```

## Technical Notes
- The design uses Flexbox for modern layout capabilities
- Card hover effects provide subtle visual feedback
- Responsive breakpoints ensure the design works on mobile devices
- Placeholders are included for missing data (like company logos)
- Helper functions enhance the template capabilities without overcomplicating the HTML
- Consider including schema.org microdata for job listings in a future iteration

- Access to job match data
- CSS framework used in the project
- Font Awesome for icons
