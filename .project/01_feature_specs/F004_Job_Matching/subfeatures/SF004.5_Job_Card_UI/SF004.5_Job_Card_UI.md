# SF004.5: Job Card UI

## Subfeature Overview
The Job Card UI subfeature implements the visual presentation of job matches to users. It creates an intuitive, card-based interface that displays essential job information, match quality indicators, and LLM-generated match explanations in a format that encourages user interaction and feedback.

### Card Design Requirements
Each job card should include:
- Job title
- Company name
- Company logo (if available)
- Match percentage as a visual indicator
- Brief LLM-generated match explanation
- "Interested" and "Not Interested" buttons
- "Tell us why" dropdown for feedback

### UI/UX Guidelines
- Cards should have a clean, modern design
- Visual hierarchy should prioritize critical information
- Match percentage should be immediately visible
- Cards should have a consistent height but accommodate variable content
- Interaction elements should be intuitive and accessible
- Responsive design for both desktop and mobile viewing
- Animations for card transitions (fade in/out when voting)
