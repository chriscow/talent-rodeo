# SF004.5: Job Card UI

## Subfeature Overview
The Job Card UI subfeature implements the visual presentation of job matches to users. It creates an intuitive, card-based interface that displays essential job information, match quality indicators, and LLM-generated match explanations in a format that encourages user interaction and feedback.

### Current Implementation References

### Card Design Requirements
Each job card should include:
- Job title
- Company name
- Company logo (if available)
- LLM-generated match summary
- "Interested" and "Not Interested" buttons
- "Tell us why" feedback input when "Not Interested" is selected

### UI/UX Guidelines
- Cards should have a clean, modern design
- Visual hierarchy should prioritize critical information
- Match quality should be clearly communicated
- Cards should have a consistent height but accommodate variable content
- Interaction elements should be intuitive and accessible
- Responsive design for both desktop and mobile viewing
- Smooth transitions for card updates (fade out when voted on)
- Clear messaging when no more jobs are available to display

### User Interaction Flow
1. User is presented with job cards in the dashboard
2. User can select "Interested" or "Not Interested" for each job
3. When "Not Interested" is selected, the card slides out with a "Tell us why" feedback input box
4. After user votes, the job card fades out and a new card appears
5. If no more jobs are available, a clear message is displayed

### Feedback Collection
- When user selects "Not Interested", prompt for feedback with options:
  - Not interested in this company
  - Not interested in this role
  - Location doesn't work
  - Other (with text input)
- Store feedback in the `user_feedback` and `user_feedback_category` fields in the database
- Use feedback to improve future matches and algorithm refinement
