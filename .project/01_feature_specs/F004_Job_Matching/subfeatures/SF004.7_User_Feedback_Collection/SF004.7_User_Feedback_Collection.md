# SF004.7: User Feedback Collection

## Subfeature Overview
The User Feedback Collection subfeature enables users to provide explicit feedback on job matches, helping to improve future matching and personalize the job search experience. It captures structured and unstructured feedback through an intuitive interface and stores it for analysis and algorithm refinement.

### Feedback Collection Approach
The system will collect user feedback in two primary ways:
1. **Binary Feedback**: "Interested" or "Not Interested" for each job match
2. **Detailed Feedback**: When a user selects "Not Interested", they are prompted to provide a reason

### Feedback Categories
For "Not Interested" responses, the system will collect categorized feedback:
- Not interested in this company
- Not interested in this role
- Location doesn't work
- Skill mismatch
- Experience level mismatch
- Other (with free-text input)

### Technical Requirements
- Implement feedback UI components in job cards

- Create analytics framework for aggregating feedback
- Ensure all feedback interactions are asynchronous and don't disrupt the user experience

### Database Storage
- Use the `job_matches` table to store feedback:
  - `user_feedback`: Free-text feedback from the user (optional)
  - `user_feedback_category`: Categorized feedback (e.g., "Interested", "Not Interested")
- Create indexes for efficient querying of feedback data
