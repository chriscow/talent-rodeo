# T004.4.1: LLM Integration Setup

## Task Description
Set up the integration with the Large Language Model service for job match assessments, leveraging the existing NATS messaging infrastructure and minds library. This task involves creating the necessary message handlers, service connections, and data flow for asynchronous LLM processing.

## Acceptance Criteria
1. A new message handler is registered for job match assessments
2. The handler correctly receives job match data from the scoring system
3. The LLM service connection is properly configured and tested
4. Messages flow through the NATS messaging system as expected
5. Assessment results are stored in the database
6. The system handles service unavailability gracefully

## Implementation Details
1. Create a new match assessment handler in `/internal/handlers/assessment.go`:
   ```go
   package handlers

   import (
       "encoding/json"
       "fmt"
       "log"
       "time"

       "github.com/chriscow/minds"
       "github.com/nats-io/nats.go"
       "github.com/talent-rodeo/internal/config"
       "github.com/talent-rodeo/internal/models"
   )

   // Constants for NATS subjects
   const (
       MatchAssessmentSubject = "job.match.assessment"
   )

   // MatchAssessmentMessage contains the data needed for LLM assessment
   type MatchAssessmentMessage struct {
       JobMatchID      int                 `json:"job_match_id"`
       UserID          int                 `json:"user_id"`
       JobID           int                 `json:"job_id"`
       RawScore        int                 `json:"raw_score"`
       MatchPercentage int                 `json:"match_percentage"`
       CandidateSkills []models.CandidateSkill `json:"candidate_skills"`
       JobDetails      models.Job          `json:"job_details"`
       SkillMatches    []models.SkillMatch `json:"skill_matches"`
   }

   // SetupMatchAssessmentHandler initializes the match assessment message handler
   func SetupMatchAssessmentHandler(app *config.Application) error {
       // Subscribe to match assessment messages
       _, err := app.NatsConn.QueueSubscribe(MatchAssessmentSubject, "match-assessment-group", func(msg *nats.Msg) {
           // Parse message
           var assessmentMsg MatchAssessmentMessage
           if err := json.Unmarshal(msg.Data, &assessmentMsg); err != nil {
               log.Printf("Error unmarshaling match assessment message: %v", err)
               return
           }

           log.Printf("Processing match assessment for JobMatchID: %d", assessmentMsg.JobMatchID)

           // Process match assessment
           err := processMatchAssessment(app, assessmentMsg)
           if err != nil {
               log.Printf("Error processing match assessment: %v", err)
               // TODO: Implement retry logic in task T004.4.3
           }
       })

       return err
   }

   // processMatchAssessment handles the LLM assessment of a job match
   func processMatchAssessment(app *config.Application, msg MatchAssessmentMessage) error {
       // TODO: Complete prompt design in task T004.4.2
       
       // Simplified placeholder implementation
       client := minds.NewClient(app.LLMConfig.APIKey, app.LLMConfig.Model)
       
       // Set timeout
       ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
       defer cancel()
       
       // Placeholder for actual prompt
       prompt := fmt.Sprintf(
           "Analyze this job match (score: %d%%). Job title: %s. "+
           "Provide a rating (1-5) and brief explanation.",
           msg.MatchPercentage,
           msg.JobDetails.Title,
       )
       
       // Call LLM API
       response, err := client.Complete(ctx, prompt, minds.CompletionOptions{
           MaxTokens: 256,
       })
       
       if err != nil {
           return fmt.Errorf("LLM API error: %w", err)
       }
       
       // Parse response (simplified - will be enhanced in prompt design task)
       rating := 3 // Default
       explanation := response.Text
       
       // Update job match with assessment
       return app.JobMatches.UpdateAssessment(
           msg.JobMatchID, 
           rating, 
           explanation,
       )
   }

   // QueueMatchAssessment queues a job match for LLM assessment
   func QueueMatchAssessment(app *config.Application, jobMatch *models.JobMatch, job models.Job, skills []models.CandidateSkill, skillMatches []models.SkillMatch) error {
       // Create assessment message
       msg := MatchAssessmentMessage{
           JobMatchID:      jobMatch.ID,
           UserID:          jobMatch.UserID,
           JobID:           jobMatch.JobID,
           RawScore:        jobMatch.RawScore,
           MatchPercentage: jobMatch.MatchPercentage,
           CandidateSkills: skills,
           JobDetails:      job,
           SkillMatches:    skillMatches,
       }
       
       // Serialize message
       data, err := json.Marshal(msg)
       if err != nil {
           return fmt.Errorf("error marshaling match assessment message: %w", err)
       }
       
       // Publish to NATS
       return app.NatsConn.Publish(MatchAssessmentSubject, data)
   }
   ```

2. Update the JobMatchModel in `/internal/models/job_match.go` to add the UpdateAssessment method:
   ```go
   // UpdateAssessment updates the LLM assessment for a job match
   func (m *JobMatchModel) UpdateAssessment(id int, rating int, explanation string) error {
       stmt := `
           UPDATE job_matches
           SET llm_rating = $1, 
               llm_explanation = $2,
               updated_at = NOW()
           WHERE id = $3
       `
       
       _, err := m.DB.Exec(stmt, rating, explanation, id)
       return err
   }
   ```

## Technical Notes
- NATS provides reliable asynchronous message delivery
- Using queue subscription ensures only one worker processes each message
- The LLM timeout should be set appropriately to prevent hanging requests
- This implementation assumes the LLM service is already configured in the application
- Consider implementing a dead-letter queue for failed messages
