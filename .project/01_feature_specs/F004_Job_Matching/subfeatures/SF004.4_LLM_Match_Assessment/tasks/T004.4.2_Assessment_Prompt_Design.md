# T004.4.2: Assessment Prompt Design

## Task Description
Design and implement effective prompts for the LLM to analyze job matches and provide structured, useful assessments. The prompts should guide the LLM to generate consistent, high-quality evaluations that highlight the strengths and weaknesses of each match.

## Acceptance Criteria
1. The prompt effectively communicates the task to the LLM
2. The LLM consistently produces structured assessments with:
   - A numerical rating on a 1-5 scale
   - A concise explanation (2-3 sentences)
   - Identification of key matching points
   - Identification of potential skill gaps
3. The prompt includes instructions for output formatting
4. The generated assessments are helpful and relevant to users
5. The prompt is optimized for token efficiency

## Implementation Details
1. Update the `processMatchAssessment` function in `/internal/handlers/assessment.go` with a well-designed prompt:
   ```go
   func processMatchAssessment(app *config.Application, msg MatchAssessmentMessage) error {
       client := minds.NewClient(app.LLMConfig.APIKey, app.LLMConfig.Model)
       
       ctx, cancel := context.WithTimeout(context.Background(), app.LLMConfig.Timeout)
       defer cancel()
       
       // Build skill match information
       matchingSkills := []string{}
       missingSkills := []string{}
       
       for _, skillMatch := range msg.SkillMatches {
           // Find the skill name from candidate skills
           skillName := ""
           for _, skill := range msg.CandidateSkills {
               if skill.ID == skillMatch.SkillID {
                   skillName = skill.Name
                   break
               }
           }
           
           if skillName == "" {
               continue
           }
           
           if skillMatch.IsMatch {
               matchingSkills = append(matchingSkills, skillName)
           } else {
               missingSkills = append(missingSkills, skillName)
           }
       }
       
       // Build the prompt
       prompt := `
       You are an expert career advisor analyzing a job match. Review the information below and provide an assessment of how well the candidate's skills match the job requirements.
       
       # JOB INFORMATION
       Title: {{.JobTitle}}
       Company: {{.JobCompany}}
       Description: {{.JobDescription}}
       
       # MATCH DETAILS
       Raw Match Score: {{.RawScore}}
       Match Percentage: {{.MatchPercentage}}%
       
       # CANDIDATE SKILLS
       Matching Skills: {{.MatchingSkills}}
       Missing Skills: {{.MissingSkills}}
       
       # ASSESSMENT INSTRUCTIONS
       1. Give a rating from 1-5 (where 1 is poor match and 5 is excellent match)
       2. Provide a 2-3 sentence explanation of the overall match quality
       3. List the top 3 strengths of this match (or fewer if there aren't 3)
       4. List the top 2 potential gaps or areas for improvement
       
       # OUTPUT FORMAT
       Return your assessment in the following JSON format:
       {
           "rating": <1-5>,
           "explanation": "<your 2-3 sentence explanation>",
           "strengths": ["<strength 1>", "<strength 2>", "<strength 3>"],
           "gaps": ["<gap 1>", "<gap 2>"]
       }
       
       Ensure you only return valid JSON without any markdown formatting or additional text.
       `
       
       // Replace placeholders with actual data
       promptData := map[string]interface{}{
           "JobTitle":       msg.JobDetails.Title,
           "JobCompany":     msg.JobDetails.Company,
           "JobDescription": summarizeText(msg.JobDetails.Description, 500), // Truncate long descriptions
           "RawScore":       msg.RawScore,
           "MatchPercentage": msg.MatchPercentage,
           "MatchingSkills": strings.Join(matchingSkills, ", "),
           "MissingSkills":  strings.Join(missingSkills, ", "),
       }
       
       // Process the template
       tmpl, err := template.New("prompt").Parse(prompt)
       if err != nil {
           return fmt.Errorf("error parsing prompt template: %w", err)
       }
       
       var promptBuf bytes.Buffer
       if err := tmpl.Execute(&promptBuf, promptData); err != nil {
           return fmt.Errorf("error executing prompt template: %w", err)
       }
       
       // Call LLM API
       response, err := client.Complete(ctx, promptBuf.String(), minds.CompletionOptions{
           MaxTokens: 512,
           Temperature: 0.3, // Lower temperature for more consistent responses
       })
       
       if err != nil {
           return fmt.Errorf("LLM API error: %w", err)
       }
       
       // Parse JSON response
       var result struct {
           Rating      int      `json:"rating"`
           Explanation string   `json:"explanation"`
           Strengths   []string `json:"strengths"`
           Gaps        []string `json:"gaps"`
       }
       
       if err := json.Unmarshal([]byte(response.Text), &result); err != nil {
           log.Printf("Error parsing LLM response as JSON: %v. Raw response: %s", err, response.Text)
           
           // Fallback to default values
           result.Rating = 3
           result.Explanation = "Unable to parse LLM response. The match quality is estimated based on skill overlap."
       }
       
       // Validate rating is within range
       if result.Rating < 1 || result.Rating > 5 {
           result.Rating = 3 // Default to middle value if invalid
       }
       
       // Format final explanation with strengths and gaps
       finalExplanation := result.Explanation + "\n\n"
       
       if len(result.Strengths) > 0 {
           finalExplanation += "Strengths:\n"
           for _, strength := range result.Strengths {
               finalExplanation += "• " + strength + "\n"
           }
           finalExplanation += "\n"
       }
       
       if len(result.Gaps) > 0 {
           finalExplanation += "Areas for improvement:\n"
           for _, gap := range result.Gaps {
               finalExplanation += "• " + gap + "\n"
           }
       }
       
       // Update job match with assessment
       return app.JobMatches.UpdateAssessment(
           msg.JobMatchID, 
           result.Rating, 
           finalExplanation,
       )
   }
   
   // Helper function to summarize long text
   func summarizeText(text string, maxLength int) string {
       if len(text) <= maxLength {
           return text
       }
       return text[:maxLength] + "..."
   }
   ```

## Technical Notes
- The prompt includes detailed instructions to guide the LLM's output format
- Using JSON output format makes parsing more reliable
- Lower temperature (0.3) helps ensure consistent, predictable responses
- The fallback mechanism ensures the system works even if the LLM response isn't as expected
- Consider monitoring and logging prompt performance for continuous improvement
