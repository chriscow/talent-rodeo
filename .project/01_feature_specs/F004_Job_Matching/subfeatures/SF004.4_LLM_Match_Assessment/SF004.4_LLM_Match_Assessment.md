# SF004.4: LLM Match Assessment

## Subfeature Overview
The LLM Match Assessment subfeature enhances job matching with AI-powered analysis to provide qualitative assessments of match quality. It leverages large language models to analyze both candidate skills and job requirements, generating explanations of the match quality and identifying key strengths and potential gaps.

## Implementation Status
- **LLM Integration Setup**: Not Implemented

## Detailed Specifications

### Current Implementation References
- Preliminary implementation in `/internal/handlers/assessment.go`: Contains initial LLM integration
- NATS messaging infrastructure in `/internal/handlers/generic_handler.go`
- Library integration with `github.com/chriscow/minds`

### Assessment Approach
For the MVP, the system will implement a single-stage LLM analysis that:
1. Receives candidate information and job details
2. Analyzes the match quality based on skills and experience
3. Produces a structured assessment with:
   - Overall rating (1-5 scale)
   - Brief explanation (2-3 sentences)
   - Key matching points and potential gaps

### Technical Requirements
- Implement LLM integration using the existing `minds` library
- Design effective prompts that produce consistent, actionable assessments
- Ensure efficient handling of API quota limitations
- Implement robust error handling with exponential backoff for retries
- Store assessment results in the database for future reference
- Use NATS messaging for non-blocking processing

## Error Handling Strategy
- Implement retry logic with exponential backoff for transient failures
- Handle rate limiting by backing off when being throttled
- Log detailed error information for debugging
- Fall back to basic match data when LLM assessment fails
