# SF004.3: Match Scoring Algorithm

## Subfeature Overview
The Match Scoring Algorithm subfeature implements a weighted scoring system that evaluates how well a candidate's skills align with job requirements. It calculates a raw score based on skill matches, normalizes the score to a percentage, and applies a threshold to filter out low-quality matches.

### Scoring Formula
The algorithm will implement the following approach:

1. **Raw Score Calculation**:
   - +10 points for each "Must Have" skill match
   - +5 points for each "Preferred" skill match

2. **Normalization Formula**:
   ```go
   // Calculate max possible score
   maxPossibleScore := len(mustHaveSkills)*10 + len(preferredSkills)*5

   // Normalize to percentage (preventing division by zero)
   matchPercentage := 0
   if maxPossibleScore > 0 {
       matchPercentage = (rawScore * 100) / maxPossibleScore
   }
   ```

3. **Threshold Application**:
   - Jobs with match percentage < 30% will be filtered out
   - This threshold can be adjusted in configuration
