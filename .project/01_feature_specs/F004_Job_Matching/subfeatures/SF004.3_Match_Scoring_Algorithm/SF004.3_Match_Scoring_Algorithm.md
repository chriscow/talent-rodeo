# SF004.3: Match Scoring Algorithm

## Subfeature Overview
The Match Scoring Algorithm subfeature implements a weighted scoring system that evaluates how well a candidate's skills align with job requirements. It calculates a raw score based on skill matches, normalizes the score to a percentage, and applies a threshold to filter out low-quality matches.

### Scoring Formula
The algorithm will implement the following approach:

1. **Raw Score Calculation**:
   - +10 points for each "Must Have" skill match
   - +5 points for each "Preferred" skill match

2. **Normalization Formula**:
   ```go
   // Calculate raw score
   rawScore := 0
   for _, skill := range candidateSkills {
       if jobHasSkill(job, skill) {
           if skill.IsMustHave {
               rawScore += 10
           } else {
               rawScore += 5
           }
       }
   }

   // Calculate max possible score
   maxPossibleScore := len(mustHaveSkills)*10 + len(preferredSkills)*5

   // Normalize to percentage (preventing division by zero)
   matchPercentage := 0
   if maxPossibleScore > 0 {
       matchPercentage = (rawScore * 100) / maxPossibleScore
   }

   // Apply minimum threshold (e.g., 30%)
   if matchPercentage < 30 {
       // Don't display this job
   }
   ```

### Job Skill Matching Implementation
- The `jobHasSkill` function will use an LLM prompt to determine if a skill is present in a job description
- The LLM will return a structured JSON response indicating whether the skill (or synonym) is explicitly stated
- Example implementation:
  ```go
  type SkillMatchResponse struct {
      IsMatch bool    `json:"is_match"`
      Confidence float64 `json:"confidence"`
      Reasoning string `json:"reasoning"`
  }

  func jobHasSkill(job Job, skill CandidateSkill) bool {
      // Create prompt for LLM to check if job description contains the skill
      prompt := fmt.Sprintf(
          "Job Description: %s\nSkill to check: %s\nDoes this job explicitly require or mention this skill or any synonyms? Respond with JSON.",
          job.Description,
          skill.Name,
      )
      
      // Call LLM API and parse structured response
      response, err := callLLM(prompt)
      if err != nil {
          log.Printf("Error calling LLM: %v", err)
          return false // Default to false if error
      }
      
      var result SkillMatchResponse
      if err := json.Unmarshal([]byte(response), &result); err != nil {
          log.Printf("Error parsing LLM response: %v", err)
          return false
      }
      
      return result.IsMatch
  }
  ```
