# T004.3.3: Score Threshold Implementation

## Task Description
Implement the score threshold component of the match algorithm that filters out job matches with scores below a minimum threshold. This ensures that only jobs with a meaningful level of match quality are presented to users.

## Acceptance Criteria
1. Jobs with match percentages below the configured threshold (default 30%) are filtered out
2. The threshold is configurable via application settings
3. Appropriate logging is added when jobs are filtered out
4. The UI handles the case where all jobs are filtered out gracefully
5. Super users have the ability to view matches below the threshold for quality control

## Implementation Details
1. Add a configurable threshold to the application config in `/internal/config/config.go`:
   ```go
   // Application contains application-wide dependencies
   type Application struct {
       // existing fields
       MatchThreshold int // Minimum percentage for job matches to be displayed
   }
   ```

2. Set a default value in the application setup in `/cmd/web/main.go`:
   ```go
   // Initialize app with default values
   app := &config.Application{
       // existing fields
       MatchThreshold: 30, // Default 30% threshold
   }
   
   // Allow override via environment variable
   if thresholdStr := os.Getenv("MATCH_THRESHOLD"); thresholdStr != "" {
       if threshold, err := strconv.Atoi(thresholdStr); err == nil {
           app.MatchThreshold = threshold
       } else {
           errorLog.Printf("Invalid MATCH_THRESHOLD value: %s, using default", thresholdStr)
       }
   }
   ```

3. Update the `scoreJobs` function in `/internal/handlers/search.go` to apply threshold filtering:
   ```go
   // After calculating scores and normalization
   
   // Apply threshold filter
   var filteredJobs []ScoredJob
   for _, job := range scoredJobs {
       if job.Percentage >= app.MatchThreshold {
           filteredJobs = append(filteredJobs, job)
       } else {
           log.Printf("Job %d filtered out: score %d%% below threshold %d%%", 
               job.Job.ID, job.Percentage, app.MatchThreshold)
       }
   }
   
   // Check if we have any jobs after filtering
   if len(filteredJobs) == 0 {
       log.Printf("All jobs filtered out by threshold (%d%%)", app.MatchThreshold)
       // Still store the matches in database, but return empty list
       if err := storeJobMatches(scoredJobs, app); err != nil {
           return nil, fmt.Errorf("error storing job matches: %w", err)
       }
       return []ScoredJob{}, nil
   }
   
   // Store all matches in database, even those below threshold
   if err := storeJobMatches(scoredJobs, app); err != nil {
       return nil, fmt.Errorf("error storing job matches: %w", err)
   }
   
   // Return only filtered jobs that meet threshold
   return filteredJobs, nil
   ```

4. Add a handler for super users to view all matches including those below threshold:
   ```go
   // HandleAllMatches shows all job matches including those below threshold (for super users only)
   func (app *config.Application) HandleAllMatches(w http.ResponseWriter, r *http.Request) {
       // Check if user is a super user
       user := app.authenticatedUser(r)
       if user == nil || !user.IsSuperUser {
           app.clientError(w, http.StatusForbidden)
           return
       }
       
       // Get all matches without threshold filtering
       userID := user.ID
       matches, err := app.JobMatches.GetMatchesForUser(userID)
       if err != nil {
           app.serverError(w, err)
           return
       }
       
       // Render template with all matches
       app.render(w, r, "all_matches.page.tmpl", &templateData{
           Matches: matches,
           ThresholdOverride: true,
       })
   }
   ```

5. Update the search results template to handle empty results gracefully:
   ```html
   <!-- In search_results.page.tmpl -->
   {{if .ScoredJobs}}
       <!-- Regular job display code -->
   {{else}}
       <div class="alert alert-info">
           <h4>No matching jobs found</h4>
           <p>We couldn't find any jobs that match your skills above our {{.MatchThreshold}}% threshold.</p>
           <p>Consider:</p>
           <ul>
               <li>Adding more skills to your profile</li>
               <li>Adjusting your location preferences</li>
               <li>Trying a broader search query</li>
           </ul>
       </div>
   {{end}}
   ```

## Technical Notes
- The threshold filtering occurs after normalization
- All matches are still stored in the database for analysis, even those below threshold
- The threshold is configurable to allow for tuning based on user feedback
- Super users can access all matches regardless of threshold for quality control
- Consider adding analytics to track how many jobs are being filtered out
