# T004.3.2: Score Normalization

## Task Description
Implement the score normalization component of the match algorithm that converts raw scores to percentage-based match scores. This normalization makes match scores comparable across different jobs with varying numbers of skills.

## Acceptance Criteria
1. Raw scores are correctly normalized to a percentage scale (0-100%)
2. The normalization formula accounts for the maximum possible score based on user's skills
3. Division by zero is properly handled when no skills data is available
4. The normalized percentage is stored in the `job_matches` table
5. The normalization is applied consistently across all job matches

   // calculateMaxPossibleScore determines the maximum points a job could score
   func calculateMaxPossibleScore(skills []models.CandidateSkill) int {
       maxScore := 0
       for _, skill := range skills {
           if skill.IsMustHave {
               maxScore += 10
           } else {
               maxScore += 5
           }
       }
       return maxScore
   }
