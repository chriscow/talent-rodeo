# T004.1.1: Location UI Component

## Task Description
Implement a location preference dropdown UI component that allows users to select from supported metropolitan areas or choose "Fully Remote". This component will be integrated into the existing preferences form.

## Acceptance Criteria
1. A dropdown component is added to the preferences form
2. The dropdown includes "Fully Remote" as the first option
3. The dropdown includes the top 5 metropolitan areas:
   - San Francisco Bay Area
   - New York City
   - Seattle
   - Austin
   - Boston
4. The currently selected location is highlighted in the dropdown
5. Help text clearly indicates that only listed locations are supported in the MVP
6. The UI is responsive and works on both desktop and mobile devices

## Implementation Details
1. Modify the preferences template file at `/cmd/web/templates/preferences.html`
2. Add the following HTML structure:
   ```html
   <div class="form-group">
     <label for="location-preference">Location Preference</label>
     <select id="location-preference" name="location_preference" class="form-control">
       <option value="remote">Fully Remote</option>
       <option value="sf">San Francisco Bay Area</option>
       <option value="nyc">New York City</option>
       <option value="sea">Seattle</option>
       <option value="aus">Austin</option>
       <option value="bos">Boston</option>
     </select>
     <small class="form-text text-muted">Only these locations are supported for the current version. More options coming soon!</small>
   </div>
   ```
3. Update the CSS styling to match the existing form components
4. Ensure the form reflects the user's current preference if already set

## Technical Notes
- The location values in the dropdown should match the GeoID mapping that will be implemented in the backend
- Frontend validation should ensure a valid selection before form submission
- The component should integrate with the existing form validation system

## Dependencies
- Existing preferences form structure
- CSS styling framework used in the project
