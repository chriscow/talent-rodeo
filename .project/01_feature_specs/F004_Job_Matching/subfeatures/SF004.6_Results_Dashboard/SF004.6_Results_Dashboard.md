# SF004.6: Results Dashboard

## Subfeature Overview
The Results Dashboard subfeature implements a comprehensive interface for displaying job matches to users. It presents job cards in an organized layout, shows search progress information, and provides navigation between current matches and historical job views. This dashboard serves as the main interface for users to interact with their job matches.

### Dashboard Components
The dashboard consists of three main components:
1. **Status Bar**: Non-scrolling header showing search progress metrics
2. **Job Card Display Area**: Main content area displaying job cards in a responsive grid
3. **Tabbed Navigation**: Allows switching between current matches and history

### Status Bar Requirements
- Display number of jobs searched
- Display number of matches found
- Show next scheduled search time (based on subscription tier)
- Remain visible at the top of the page during scrolling

### Card Display Logic
- Display 3 job cards at a time for focused review
- Implement smooth transitions when cards are voted on
- Support pagination or "load more" functionality
- Ensure responsive layout across device sizes

### History Tab Requirements
- Provide access to all previously viewed jobs
- Allow filtering by user feedback (Interested/Not Interested)
- Display date when job was first shown
- Enable revisiting and updating feedback on historical matches
