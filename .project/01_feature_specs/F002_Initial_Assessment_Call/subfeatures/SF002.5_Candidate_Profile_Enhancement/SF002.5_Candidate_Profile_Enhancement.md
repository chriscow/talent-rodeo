# SF002.5: Candidate Profile Enhancement

## Overview
The Candidate Profile Enhancement subfeature transforms raw extracted information from the assessment call into a comprehensive, structured, and validated candidate profile. This subfeature includes processes for data enrichment, validation, categorization, and prioritization to create a highly accurate and useful profile for job matching and candidate management.

## Status
**Partially Implemented**

## Detailed Requirements

### Profile Data Integration
1. Consolidate information from multiple sources:
   - Initial user registration data
   - Uploaded resume data
   - LinkedIn profile imports
   - Assessment call extractions
   - User-provided profile edits
2. Resolve conflicts between different data sources
3. Apply source-based confidence weighting
4. Maintain data provenance for each profile attribute
5. Log all profile update events with timestamps and sources

### Profile Data Enrichment
1. Expand abbreviated information into comprehensive details
2. Research and validate company information
   - Size, industry, and company type
   - Geographic location
   - Years of operation
3. Standardize and categorize skills
   - Map to standard skill taxonomy
   - Assign skill categories (technical, soft, domain)
   - Determine related skills
4. Infer missing details based on available information
5. Calculate derived metrics:
   - Total years of relevant experience
   - Recency of skill usage
   - Career trajectory

### Profile Validation
1. Identify and flag inconsistencies in the profile
   - Timeline gaps or overlaps
   - Skill levels inconsistent with experience
   - Contradictory preferences
2. Validate against external data sources where possible
3. Generate confidence scores for profile sections
4. Create prioritized list of missing or uncertain information
5. Design follow-up questions to resolve uncertainties

### Profile Summarization
1. Generate concise text summaries of candidate qualifications
2. Create skill highlight sections showing top skills
3. Identify candidate's primary value proposition
4. Summarize candidate preferences and requirements
5. Generate "candidate at a glance" section for recruiters
6. Prepare job-specific summaries highlighting relevant qualifications

### Career Insights Generation
1. Analyze career progression and growth trajectory
2. Identify career strengths and potential gaps
3. Compare to industry norms for similar roles
4. Generate suggestions for skill development
5. Identify optimal career paths based on profile

## User Experience
1. Display an enhanced profile dashboard after assessment call
2. Allow candidates to review and edit enhanced profile data
3. Highlight newly added or updated information
4. Provide confidence indicators for profile sections
5. Allow candidates to confirm or correct enriched data
6. Offer suggestions for profile improvements

## Usage Examples

### Profile Integration Process
```go
func integrateProfileData(ctx context.Context, db *sql.DB, candidateID int64, newData *ProfileData, source string) error {
    // Fetch existing profile data
    existingData, err := getCandidateProfile(db, candidateID)
    if err != nil {
        return fmt.Errorf("failed to get existing profile: %w", err)
    }
    
    // Resolve conflicts and integrate new data
    integratedData, changeLog := resolveAndIntegrateData(existingData, newData, source)
    
    // Apply changes to database
    tx, err := db.BeginTx(ctx, nil)
    if err != nil {
        return fmt.Errorf("failed to begin transaction: %w", err)
    }
    defer tx.Rollback()
    
    if err := updateCandidateProfile(ctx, tx, candidateID, integratedData); err != nil {
        return fmt.Errorf("failed to update profile: %w", err)
    }
    
    // Log all changes
    for _, change := range changeLog {
        if err := logProfileChange(ctx, tx, candidateID, change); err != nil {
            return fmt.Errorf("failed to log profile change: %w", err)
        }
    }
    
    // Update profile metrics
    if err := updateProfileMetrics(ctx, tx, candidateID); err != nil {
        return fmt.Errorf("failed to update profile metrics: %w", err)
    }
    
    if err := tx.Commit(); err != nil {
        return fmt.Errorf("failed to commit transaction: %w", err)
    }
    
    return nil
}
```

### Profile Validation Example
```go
func validateCandidateProfile(profile *CandidateProfile) []ValidationIssue {
    var issues []ValidationIssue
    
    // Check for timeline consistency in experiences
    timelineIssues := validateExperienceTimeline(profile.Experiences)
    issues = append(issues, timelineIssues...)
    
    // Validate skill levels against experience
    skillIssues := validateSkillsAgainstExperience(profile.Skills, profile.Experiences)
    issues = append(issues, skillIssues...)
    
    // Check for preference consistency
    preferenceIssues := validatePreferenceConsistency(profile.Preferences)
    issues = append(issues, preferenceIssues...)
    
    // Check for profile completeness
    completenessIssues := checkProfileCompleteness(profile)
    issues = append(issues, completenessIssues...)
    
    return issues
}
```

### Profile Summary Generation Example
```go
func generateProfileSummary(ctx context.Context, profile *CandidateProfile) (*ProfileSummary, error) {
    // Create input for summary generation
    input := map[string]any{
        "name": profile.FirstName + " " + profile.LastName,
        "experiences": profile.Experiences,
        "skills": profile.Skills,
        "education": profile.Education,
        "preferences": profile.Preferences,
    }
    
    // Generate general summary
    generalSummary, err := generateGeneralSummary(ctx, input)
    if err != nil {
        return nil, fmt.Errorf("failed to generate general summary: %w", err)
    }
    
    // Generate skills highlight
    skillsHighlight, err := generateSkillsHighlight(ctx, profile.Skills)
    if err != nil {
        return nil, fmt.Errorf("failed to generate skills highlight: %w", err)
    }
    
    // Generate experience summary
    experienceSummary, err := generateExperienceSummary(ctx, profile.Experiences)
    if err != nil {
        return nil, fmt.Errorf("failed to generate experience summary: %w", err)
    }
    
    // Generate career insights
    careerInsights, err := generateCareerInsights(ctx, profile)
    if err != nil {
        return nil, fmt.Errorf("failed to generate career insights: %w", err)
    }
    
    // Combine into complete profile summary
    return &ProfileSummary{
        CandidateID:       profile.ID,
        GeneralSummary:    generalSummary,
        SkillsHighlight:   skillsHighlight,
        ExperienceSummary: experienceSummary,
        CareerInsights:    careerInsights,
        GeneratedAt:       time.Now(),
        Version:           1,
    }, nil
}
```
