# T002.5.1: Implement Profile Enrichment

## Task Description
Implement a comprehensive candidate profile enrichment system that transforms extracted information from assessment calls into a structured, enhanced candidate profile. This task involves creating mechanisms to validate, merge, and prioritize data from various sources to build an accurate and useful candidate profile for job matching.

## Project Context
Talent Rodeo's Initial Assessment Call feature (F002) gathers information from candidates through automated phone interviews. The Candidate Profile Enhancement subfeature (SF002.5) needs to take information extracted from these calls (by SF002.3) and intelligently integrate it with existing profile data to create comprehensive candidate profiles that can be used for effective job matching.

## Implementation Details

### Profile Data Integration
1. Create a profile integration pipeline that:
   - Collects data from multiple sources (resume, LinkedIn, assessment call)
   - Resolves conflicts between different data sources
   - Assigns confidence scores to profile elements
   - Identifies gaps requiring further information
2. Implement data source prioritization:
   - Define rules for source precedence (e.g., explicit statements in calls override resume in some cases)
   - Create conflict resolution strategies
   - Implement version tracking for profile changes
3. Develop profile validation:
   - Create validation rules for different profile elements
   - Implement checks for completeness and consistency
   - Flag questionable or low-confidence data

### Skill Profile Enhancement
1. Create a comprehensive skill profile:
   - Organize skills by category (technical, soft, domain-specific)
   - Associate skills with proficiency levels
   - Link skills to relevant experiences
   - Add recency and relevance indicators
2. Implement skill relationship mapping:
   - Connect related skills
   - Identify skill gaps based on stated experience
   - Suggest complementary skills
3. Create skill prioritization:
   - Rank skills based on stated preferences
   - Identify primary vs. secondary skills
   - Flag skills the candidate wants to avoid

### Experience Enhancement
1. Structure experience information:
   - Create a chronological work history
   - Extract and highlight key responsibilities
   - Identify and emphasize notable achievements
   - Connect technologies and methodologies to roles
2. Implement experience validation:
   - Check for timeline consistency
   - Validate role progression
   - Identify gaps in employment history
3. Create experience summarization:
   - Generate concise role summaries
   - Extract key metrics and outcomes
   - Create career progression overview

### Preference Refinement
1. Structure preference information:
   - Organize by category (location, role, company, etc.)
   - Assign priority levels
   - Identify deal-breakers vs. nice-to-haves
2. Implement preference validation:
   - Check for consistency with stated skills and experience
   - Identify unrealistic or conflicting preferences
   - Flag preferences requiring clarification
3. Create preference summary:
   - Generate a concise overview of key preferences
   - Create a prioritized list of requirements
   - Generate job matching criteria

### Profile Summary Generation
1. Create a candidate summary generator:
   - Produce concise overview of candidate strengths
   - Highlight unique selling points
   - Generate recruiter-focused summary
2. Implement profile gap analysis:
   - Identify missing information
   - Generate suggested follow-up questions
   - Create completion score for profile sections
3. Create profile visualizations:
   - Design skill radar/spider charts
   - Create experience timeline visualization
   - Generate preference priority visualization

### Profile Review Interface
1. Implement candidate review experience:
   - Create UI for candidates to review extracted information
   - Allow corrections and confirmations
   - Implement feedback collection on accuracy
2. Create recruiter view:
   - Design interface for recruiters to view enhanced profiles
   - Highlight confidence levels and potential issues
   - Provide filtering and search capabilities

## Database Interactions
1. Update profile data in the database:
   - Update candidate_skills table with enhanced skill information
   - Store structured experience data
   - Save refined preference information
2. Implement data versioning:
   - Track changes to profile elements
   - Maintain history of profile evolution
   - Support rollback of problematic changes

## Testing Requirements
1. Create unit tests for individual enhancement components
2. Develop integration tests for the complete pipeline
3. Test with diverse profile scenarios:
   - Technical vs. non-technical candidates
   - Entry-level vs. senior profiles
   - Specialty domain experts
4. Validate enhanced profiles against human-edited versions

## Acceptance Criteria
1. System successfully integrates data from multiple sources
2. Conflicts between data sources are intelligently resolved
3. Enhanced profiles include properly structured skills, experiences, and preferences
4. Profile confidence scores accurately reflect data reliability
5. Profile gaps are correctly identified for follow-up
6. Candidate review interface allows for corrections and confirmation
7. Enhanced profiles improve job matching accuracy

func enhanceCandidateProfile(ctx context.Context, candidateID string, extractedInfo *ExtractedInformation) (*EnhancedProfile, error) {
    // Fetch existing profile data
    existingProfile, err := getCandidateProfile(ctx, candidateID)
    if err != nil {
        return nil, fmt.Errorf("failed to get existing profile: %w", err)
    }
    
    // Create enhanced profile
    enhanced := &EnhancedProfile{
        CandidateID: candidateID,
        Skills:      mergeSkills(existingProfile.Skills, extractedInfo.Skills),
        Experiences: mergeExperiences(existingProfile.Experiences, extractedInfo.Experiences),
        Preferences: mergePreferences(existingProfile.Preferences, extractedInfo.Preferences),
    }
    
    // Generate profile summary
    summary, err := generateProfileSummary(enhanced)
    if err != nil {
        return nil, fmt.Errorf("failed to generate profile summary: %w", err)
    }
    enhanced.Summary = summary
    
    // Analyze profile completeness
    completeness := analyzeProfileCompleteness(enhanced)
    enhanced.CompletenessScore = completeness.Score
    enhanced.MissingElements = completeness.MissingElements
    
    return enhanced, nil
}

// mergeSkills combines existing skills with newly extracted skills
func mergeSkills(existing []Skill, extracted []ExtractedSkill) []EnhancedSkill {
    skillMap := make(map[string]*EnhancedSkill)
    
    // First add existing skills to the map
    for _, skill := range existing {
        skillMap[normalizeSkillName(skill.Name)] = &EnhancedSkill{
            Name:         skill.Name,
            Proficiency:  skill.Proficiency,
            YearsUsed:    skill.YearsUsed,
            IsPreferred:  skill.Preference > 3,
            IsAvoid:      skill.Preference < 2,
            Confidence:   0.8, // Higher confidence for existing data
            Sources:      []string{"resume", "profile"},
        }
    }
    
    // Merge in extracted skills
    for _, extracted := range extracted {
        normalized := normalizeSkillName(extracted.Name)
        if existing, ok := skillMap[normalized]; ok {
            // Update existing skill
            if extracted.Confidence > 0.7 {
                // Only update if extraction has high confidence
                if extracted.Proficiency != "" {
                    existing.Proficiency = extracted.Proficiency
                }
                if extracted.YearsExperience > 0 {
                    existing.YearsUsed = extracted.YearsExperience
                }
            }
            // Add source and update confidence
            existing.Sources = append(existing.Sources, "assessment_call")
            existing.Confidence = max(existing.Confidence, extracted.Confidence)
        } else {
            // Add new skill
            skillMap[normalized] = &EnhancedSkill{
                Name:        extracted.Name,
                Proficiency: extracted.Proficiency,
                YearsUsed:   extracted.YearsExperience,
                IsPreferred: extracted.IsDesired,
                IsAvoid:     extracted.IsUnwanted,
                Confidence:  extracted.Confidence,
                Sources:     []string{"assessment_call"},
            }
        }
    }
    
    // Convert map back to slice
    result := make([]EnhancedSkill, 0, len(skillMap))
    for _, skill := range skillMap {
        result = append(result, *skill)
    }
    
    // Sort by preference, then confidence
    sort.Slice(result, func(i, j int) bool {
        if result[i].IsPreferred != result[j].IsPreferred {
            return result[i].IsPreferred
        }
        return result[i].Confidence > result[j].Confidence
    })
    
    return result
}
