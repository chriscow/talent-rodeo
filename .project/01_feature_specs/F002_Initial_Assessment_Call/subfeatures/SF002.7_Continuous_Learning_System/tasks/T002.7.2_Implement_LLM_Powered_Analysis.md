# T002.7.2: Implement LLM-Powered Analysis

## Task Description
Implement a background service that uses LLMs to analyze interview transcripts, job search results, and user feedback to extract insights, identify patterns, and generate improvement suggestions for the platform. This service will work asynchronously to process data and feed its findings into the continuous learning system.

## Acceptance Criteria
- Create a background job system for LLM analysis that:
  - Processes interview transcripts and extracts improvement patterns
  - Analyzes job search results and user interactions
  - Reviews user feedback on job matches
  - Generates "What we learned and how we can adjust" reports
  - Identifies potential prompt improvements
  - Suggests search algorithm adjustments
  - Scores confidence in its recommendations
- Implement efficient batching of analysis tasks
- Create a robust error handling and retry mechanism
- Include rate limiting to manage API costs
- Design a prioritization system for analysis tasks
- Support different analysis types with specialized prompts
- Implement storage of analysis results in the learning data schema
- Create monitoring and reporting for analysis activities
- Develop a feedback loop for validating suggested improvements

## Technical Details

### Analysis Workflow
The analysis service will follow these steps:
1. **Data Collection**: Gather relevant data (transcripts, feedback, search results)
2. **Preprocessing**: Format data for LLM consumption
3. **LLM Analysis**: Send to appropriate LLM with specialized prompts
4. **Insight Extraction**: Parse LLM output for structured insights
5. **Validation**: Apply validation rules to insights
6. **Storage**: Store validated insights in learning database
7. **Notification**: Alert appropriate stakeholders to new insights

### Background Job Implementation
The analysis will be implemented as background jobs using a worker pool pattern:

```go
type AnalysisWorker struct {
    jobQueue   chan AnalysisJob
    llmClient  *LLMClient
    db         *sql.DB
    wg         sync.WaitGroup
    ctx        context.Context
    cancel     context.CancelFunc
}

type AnalysisJob struct {
    JobType     string
    InputData   map[string]interface{}
    Priority    int
    CreatedAt   time.Time
}

func NewAnalysisWorker(workerCount int, llmClient *LLMClient, db *sql.DB) *AnalysisWorker {
    ctx, cancel := context.WithCancel(context.Background())
    
    worker := &AnalysisWorker{
        jobQueue:  make(chan AnalysisJob, 100),
        llmClient: llmClient,
        db:        db,
        ctx:       ctx,
        cancel:    cancel,
    }
    
    for i := 0; i < workerCount; i++ {
        worker.wg.Add(1)
        go worker.processJobs(i)
    }
    
    return worker
}

func (w *AnalysisWorker) processJobs(workerID int) {
    defer w.wg.Done()
    
    for {
        select {
        case job := <-w.jobQueue:
            log.Printf("Worker %d processing job of type %s", workerID, job.JobType)
            
            var err error
            switch job.JobType {
            case "transcript_analysis":
                err = w.processTranscriptAnalysis(job)
            case "feedback_analysis":
                err = w.processFeedbackAnalysis(job)
            default:
                err = fmt.Errorf("unknown job type: %s", job.JobType)
            }
            
            if err != nil {
                log.Printf("Error processing job: %v", err)
                // Implement retry logic here
            }
            
        case <-w.ctx.Done():
            log.Printf("Worker %d shutting down", workerID)
            return
        }
    }
}
```

### Insight Storage
After analysis, insights are stored in the learning_outcomes table:

```go
func (w *AnalysisWorker) storeInsights(insights []Insight) error {
    tx, err := w.db.BeginTx(w.ctx, nil)
    if err != nil {
        return fmt.Errorf("failed to begin transaction: %w", err)
    }
    defer tx.Rollback()
    
    for _, insight := range insights {
        _, err := tx.ExecContext(
            w.ctx,
            `INSERT INTO learning_outcomes 
            (source_type, source_id, insight_type, insight_text, confidence, created_at)
            VALUES ($1, $2, $3, $4, $5, NOW())`,
            insight.SourceType,
            insight.SourceID,
            insight.InsightType,
            insight.InsightText,
            insight.Confidence,
        )
        
        if err != nil {
            return fmt.Errorf("failed to insert insight: %w", err)
        }
    }
    
    return tx.Commit()
}
```
