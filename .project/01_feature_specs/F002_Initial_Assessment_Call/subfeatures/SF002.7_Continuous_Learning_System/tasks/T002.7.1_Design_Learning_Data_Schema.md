# T002.7.1: Design Learning Data Schema

## Task Description
Design and implement a database schema to store learning outcomes, insights, and improvement suggestions generated by the continuous learning system. This schema will track the relationships between user interactions, feedback, and system improvements over time.

## Acceptance Criteria
- Create database tables for storing:
  - Learning outcomes from analysis
  - Improvement suggestions
  - Prompt versions and changes
  - Feedback patterns
  - Implementation statuses
- Define relationships between:
  - Transcripts and learning outcomes
  - User feedback and improvement suggestions
  - Prompt versions and implemented changes
- Implement version tracking for:
  - Interview prompts
  - Search algorithms
  - UI components
- Create indexing strategy for efficient querying
- Design archiving approach for historical data
- Document schema with explanatory diagrams
- Implement migration scripts
- Create Go data structures matching the schema

## Technical Details

### Database Schema Overview
```sql
-- Learning Outcomes Table
CREATE TABLE learning_outcomes (
    id SERIAL PRIMARY KEY,
    source_type VARCHAR(50) NOT NULL, -- 'transcript', 'feedback', 'search_result'
    source_id VARCHAR(100) NOT NULL,   -- Reference to source entity
    insight_type VARCHAR(50) NOT NULL, -- 'prompt_improvement', 'algorithm_adjustment', etc.
    insight_text TEXT NOT NULL,        -- The actual learning/insight
    confidence FLOAT NOT NULL,         -- Confidence score (0-1)
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    implemented BOOLEAN DEFAULT FALSE,
    implementation_id INT              -- Reference to implemented change
);

-- Prompt Versions Table
CREATE TABLE prompt_versions (
    id SERIAL PRIMARY KEY,
    prompt_type VARCHAR(50) NOT NULL,  -- 'introduction', 'skills_assessment', etc.
    version VARCHAR(20) NOT NULL,      -- Semantic versioning
    content TEXT NOT NULL,             -- The actual prompt content
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    created_by VARCHAR(100) NOT NULL,  -- User or system that created it
    learning_outcome_id INT REFERENCES learning_outcomes(id),
    is_active BOOLEAN DEFAULT FALSE,
    performance_metrics JSONB          -- Metrics for this prompt version
);

-- Feedback Patterns Table
CREATE TABLE feedback_patterns (
    id SERIAL PRIMARY KEY,
    pattern_name VARCHAR(100) NOT NULL,
    pattern_description TEXT NOT NULL,
    occurrence_count INT DEFAULT 1,
    first_detected TIMESTAMP NOT NULL DEFAULT NOW(),
    last_detected TIMESTAMP NOT NULL DEFAULT NOW(),
    status VARCHAR(20) DEFAULT 'active', -- 'active', 'addressed', 'monitoring'
    priority INT DEFAULT 3               -- 1-5 scale, 1 being highest
);

-- Implementation Records Table
CREATE TABLE implementation_records (
    id SERIAL PRIMARY KEY,
    implementation_type VARCHAR(50) NOT NULL, -- 'prompt_update', 'algorithm_change', etc.
    description TEXT NOT NULL,
    implemented_by VARCHAR(100) NOT NULL,
    implemented_at TIMESTAMP NOT NULL DEFAULT NOW(),
    related_learning_ids INT[] NOT NULL,     -- Array of learning_outcome ids
    version_before VARCHAR(20),              -- Previous version reference
    version_after VARCHAR(20) NOT NULL,      -- New version reference
    approval_status VARCHAR(20) DEFAULT 'pending'
);
```

### Go Data Structures
```go
type LearningOutcome struct {
    ID               int64
    SourceType       string
    SourceID         string
    InsightType      string
    InsightText      string
    Confidence       float64
    CreatedAt        time.Time
    Implemented      bool
    ImplementationID *int64
}

type PromptVersion struct {
    ID               int64
    PromptType       string
    Version          string
    Content          string
    CreatedAt        time.Time
    CreatedBy        string
    LearningOutcomeID *int64
    IsActive         bool
    PerformanceMetrics map[string]interface{}
}

type FeedbackPattern struct {
    ID                int64
    PatternName       string
    PatternDescription string
    OccurrenceCount   int
    FirstDetected     time.Time
    LastDetected      time.Time
    Status            string
    Priority          int
}

type ImplementationRecord struct {
    ID                int64
    ImplementationType string
    Description       string
    ImplementedBy     string
    ImplementedAt     time.Time
    RelatedLearningIDs []int64
    VersionBefore     *string
    VersionAfter      string
    ApprovalStatus    string
}
```
