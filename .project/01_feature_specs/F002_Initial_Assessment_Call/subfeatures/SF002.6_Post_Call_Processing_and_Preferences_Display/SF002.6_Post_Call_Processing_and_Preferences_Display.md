# SF002.6: Post-Call Processing and Preferences Display

## Overview
This subfeature handles the workflow after an assessment call is completed. It ensures that the information extracted from the call is properly processed, stored, and presented to the candidate for review and adjustment. The subfeature includes the processing status tracking, UI for displaying processing progress, and the enhancement of the preferences page to reflect the extracted information.

## Business Value
- **Transparency**: Provides candidates with clear visibility into how their information is being processed
- **Data Validation**: Allows candidates to verify and adjust extracted information for accuracy
- **User Experience**: Creates a seamless flow from call completion to preferences review
- **Customization**: Enables candidates to fine-tune their preferences for better job matches
- **Efficiency**: Automates the extraction and application of preferences from natural conversation

## User Experience
From the candidate's perspective, this subfeature provides the following experience:

1. At the end of the assessment call, they are informed that their information will be processed
2. They are told they can visit their preferences page to review the information once processing is complete
3. If they navigate to the preferences page while processing is still ongoing, they see a processing status page
4. The processing status page shows them the current status and progress of their data processing
5. Once processing is complete, they are automatically redirected to the preferences page
6. On the preferences page, they can review all the information extracted from the call
7. They can make adjustments to editable preferences as needed
8. They can see which preferences are inferred and not directly editable
9. After reviewing and adjusting preferences, they can proceed to job search

## Technical Implementation

### Processing Status Tracking
- Update database schema to track processing status, start time, end time, and details
- Implement background job system for transcript processing with status updates
- Create a status tracking service that updates the database as processing progresses

### Processing Status UI
- Design and implement a processing status page that shows:
  - Current stage of processing
  - Progress indicator
  - Estimated time remaining
  - Brief explanation of what's happening
- Implement auto-refresh functionality using HTMX or meta refresh
- Ensure the page provides clear instructions about what to expect

### Preferences Page Enhancement
- Enhance the existing preferences page to display all relevant extracted information:
  - Skills with proficiency levels
  - Salary expectations and requirements
  - Work location preferences (remote, hybrid, on-site)
  - Geographic preferences
  - Company size preferences
  - Culture and work environment preferences
  - Industry preferences
  - Other job-specific preferences
- Implement clear visual distinction between editable and non-editable preferences
- Add tooltips or explanatory text for non-editable preferences
- Ensure all editable preferences have appropriate HTMX-enabled controls

### Handler Implementation
- Create handler for the processing status page
- Enhance the preferences page handler to check processing status and redirect if needed
- Implement API endpoints for querying processing status
- Ensure proper error handling for failed processing

### Integration with Conversation System
- Update the conversation system to include appropriate ending messages
- Implement proper handoff from call completion to transcript processing
- Ensure the transcript is properly queued for processing after the call ends

## Security and Privacy Considerations
- Ensure that preferences data is only accessible to the appropriate candidate
- Implement proper authentication and authorization checks
- Use CSRF protection for all form submissions
- Ensure proper error handling that doesn't expose sensitive information
- Log processing activities for audit purposes without exposing sensitive data
