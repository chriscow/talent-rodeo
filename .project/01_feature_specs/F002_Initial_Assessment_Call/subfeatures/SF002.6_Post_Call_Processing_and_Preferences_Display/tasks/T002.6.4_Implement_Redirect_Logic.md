# Task T002.6.4: Implement Redirect Logic

## Description
Implement the logic to properly redirect users between the preferences page and processing status page based on the current processing state. This ensures users see the appropriate page when navigating to their preferences after a call and are automatically redirected to the preferences page once processing completes.

## Implementation Requirements

   ```go
   // showPreferencesPage displays the preferences page or redirects to processing status
   func (app *application) showPreferencesPage(w http.ResponseWriter, r *http.Request) {
       // Get the current user
       user := app.contextGetUser(r)
   ```

### Status Check API Endpoint
1. Create an API endpoint for checking processing status via AJAX:
   ```go
   // getProcessingStatus returns the current processing status as JSON
   func (app *application) getProcessingStatus(w http.ResponseWriter, r *http.Request) {
       // Get the current user
       user := app.contextGetUser(r)
       
       // Get the user's latest appointment
       appointment, err := app.appointments.GetLatestForUser(user.ID)
       if err != nil {
           app.serverErrorJSON(w, err)
           return
       }
       
       // Prepare response data
       response := map[string]any{
           "status": appointment.ProcessingStatus,
           "isComplete": appointment.ProcessingStatus == "completed" || appointment.ProcessingStatus == "failed",
           "details": appointment.ProcessingDetails,
       }
       
       // Write JSON response
       err = app.writeJSON(w, response, http.StatusOK)
       if err != nil {
           app.serverErrorJSON(w, err)
       }
   }
   ```

2. Add the route in `cmd/web/routes.go`:
   ```go
   router.Get("/api/processing-status", app.requireAuthentication(app.getProcessingStatus))
   ```
