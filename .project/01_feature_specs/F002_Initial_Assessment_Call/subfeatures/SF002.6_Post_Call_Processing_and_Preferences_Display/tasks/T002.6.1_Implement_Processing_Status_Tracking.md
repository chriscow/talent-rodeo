# Task T002.6.1: Implement Processing Status Tracking

## Description
Implement the backend infrastructure needed to track and update the status of transcript processing after a call is completed. This includes database schema updates, status tracking service, and background job management.

## Implementation Requirements

### Database Changes
1. Update the `appointments` table with the following fields:
   ```sql
   ALTER TABLE appointments ADD COLUMN processing_status VARCHAR(20) NOT NULL DEFAULT 'queued';
   ALTER TABLE appointments ADD COLUMN processing_started_at TIMESTAMP;
   ALTER TABLE appointments ADD COLUMN processing_completed_at TIMESTAMP;
   ALTER TABLE appointments ADD COLUMN processing_details JSONB;
   ```
   
2. Create appropriate indexes for efficient querying:
   ```sql
   CREATE INDEX idx_appointments_processing_status ON appointments(processing_status);
   CREATE INDEX idx_appointments_user_id_processing ON appointments(user_id, processing_status);
   ```

### Status Tracking Service
1. Create a `ProcessingStatusService` in `internal/services/processing_status.go` that provides:
   - Function to update processing status
   - Function to get current processing status
   - Helper functions for common status transitions

2. Implement the following status tracking functions:
   ```go
   // UpdateProcessingStatus updates the processing status for an appointment
   func (s *ProcessingStatusService) UpdateProcessingStatus(appointmentID int, status string, details map[string]any) error
   
   // GetProcessingStatus retrieves the current processing status for an appointment
   func (s *ProcessingStatusService) GetProcessingStatus(appointmentID int) (string, map[string]any, error)
   
   // MarkProcessingStarted marks an appointment as processing started
   func (s *ProcessingStatusService) MarkProcessingStarted(appointmentID int) error
   
   // MarkProcessingCompleted marks an appointment as processing completed
   func (s *ProcessingStatusService) MarkProcessingCompleted(appointmentID int) error
   
   // MarkProcessingFailed marks an appointment as processing failed
   func (s *ProcessingStatusService) MarkProcessingFailed(appointmentID int, reason string) error
   ```

### Background Job System
1. Implement a background job processor for transcript processing:
   - Create a job queue in `internal/jobs/queue.go`
   - Implement a job worker in `internal/jobs/worker.go`
   - Create a transcript processing job in `internal/jobs/transcript_processing.go`

2. Implement job status reporting:
   - Ensure jobs update the processing status as they progress
   - Implement proper error handling and reporting
   - Add logging for monitoring and debugging

### Integration Points
1. Update the call completion handler to queue a transcript processing job
2. Ensure the job processor can access the necessary services (transcript, LLM, etc.)
3. Add logic to check if processing is complete before showing preferences
