# Task T002.6.2: Create Processing Status UI

## Description
Create a user interface that displays the current status of transcript processing after a call is completed. This page will be shown to users who navigate to the preferences page while their transcript is still being processed, providing transparency and setting expectations about when they can review their preferences.

## Implementation Requirements

### Template Creation
1. Create a new template file at `assets/templates/pages/processing-status.html` with:
   - Progress indicator (such as a progress bar or spinner)
   - Current processing stage display
   - Estimated time remaining (if available)
   - Brief explanation of what's happening
   - Automatic refresh functionality

2. The template should follow this basic structure:
   ```html
   {{define "title"}}Processing Your Call - Talent Rodeo{{end}}
   
   {{define "page:main"}}
   <main class="container">
     <section>
       <header>
         <h1>Processing Your Assessment Call</h1>
       </header>
       
       <div class="processing-status">
         <div class="progress-container">
           <!-- Progress bar -->
           <progress value="{{.ProgressPercent}}" max="100"></progress>
           <p>{{.StatusMessage}}</p>
         </div>
         
         <div class="status-details">
           <p>Current stage: <strong>{{.CurrentStage}}</strong></p>
           {{if .EstimatedTimeRemaining}}
           <p>Estimated time remaining: <strong>{{.EstimatedTimeRemaining}}</strong></p>
           {{end}}
         </div>
         
         <div class="processing-explanation">
           <p>{{.ExplanationMessage}}</p>
         </div>
       </div>
     </section>
   </main>
   {{end}}
   
   {{define "page:scripts"}}
   <script>
     // Auto-refresh logic
     setTimeout(function() {
       window.location.reload();
     }, 5000);
   </script>
   {{end}}
   ```

### Handler Implementation
1. Create a handler in `cmd/web/handlers.processing.go` with:
   ```go
   // showProcessingStatusPage displays the current processing status
   func (app *application) showProcessingStatusPage(w http.ResponseWriter, r *http.Request) {
       // Implement logic to get processing status
       // Render the processing-status.html template
   }
   ```

2. Add the handler to the routes in `cmd/web/routes.go`:
   ```go
   router.Get("/profile/processing", app.requireAuthentication(app.showProcessingStatusPage))
   ```

### Status Data Preparation
1. Create a function to calculate progress percentage based on processing stage
2. Implement logic to generate appropriate status messages based on current stage
3. Implement estimated time calculation based on typical processing times

### HTMX Integration (Optional)
1. Consider using HTMX for partial page updates instead of full page refreshes:
   ```html
   <div 
     hx-get="/api/processing-status" 
     hx-trigger="every 5s"
     hx-target="this"
     hx-swap="outerHTML">
     
     <!-- Status content -->
   </div>
   ```

2. Create a corresponding API endpoint for HTMX to fetch updates:
   ```go
   // getProcessingStatusPartial returns a partial HTML update for the processing status
   func (app *application) getProcessingStatusPartial(w http.ResponseWriter, r *http.Request) {
       // Similar logic to showProcessingStatusPage but returns only the partial HTML
   }
   ```

## UI Design Details
- Use PicoCSS styling conventions
- Ensure the UI is responsive and works on mobile devices
- Use appropriate colors and animations to indicate progress
- Provide meaningful and reassuring messages to the user
- Ensure clear explanations of what's happening at each stage

## Technical Details
- Use meta refresh or JavaScript for auto-refresh (unless using HTMX)
- Ensure the page does not refresh too frequently to avoid server load
- Add logic to redirect to preferences page once processing is complete
- Handle error states with appropriate messaging
- Ensure accessibility compliance
