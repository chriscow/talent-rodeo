# T002.3.1: Implement Transcript Analysis

## Task Description
Implement a comprehensive transcript analysis system that processes conversation transcripts from automated assessment calls to extract structured information about candidates' skills, experience, and preferences. This task involves creating the necessary components to convert raw conversation data into structured, actionable insights for job matching.

## Project Context
Talent Rodeo's Initial Assessment Call feature (F002) enables automated phone interviews with candidates. After the call, the system needs to analyze the conversation to extract valuable information for the candidate's profile. The Information Extraction subfeature (SF002.3) is partially implemented, with some preference tracking and database schemas in place, but needs a complete transcript analysis implementation.

## Implementation Details

### Transcript Processing Framework
1. Create a transcript processing pipeline that:
   - Takes raw conversation transcript as input
   - Segments the conversation into meaningful chunks
   - Identifies candidate responses vs. system prompts
   - Handles speech recognition errors and uncertainties
   - Tags different types of information (skills, experiences, preferences)
2. Implement LLM-based extraction using structured prompts:
   - Create specialized prompts for different information categories
   - Design JSON schemas for structured output
   - Implement error handling for malformed responses
3. Develop confidence scoring mechanism for extracted information:
   - Score based on clarity and directness of candidate statements
   - Flag ambiguous or uncertain extractions for review
   - Handle contradictions between different statements

### Skills Extraction
1. Extract skills mentioned by candidates:
   - Technical skills with proficiency levels
   - Soft skills with supporting examples
   - Tools and technologies with experience duration
2. Implement skill normalization:
   - Map extracted skills to standardized taxonomy
   - Handle variations and synonyms
   - Associate skills with appropriate categories
3. Create proficiency assessment logic:
   - Extract explicit proficiency statements
   - Infer proficiency from context and examples
   - Implement scoring mechanism for skill confidence

### Experience Extraction
1. Extract work experience details:
   - Company names and roles
   - Time periods and durations
   - Responsibilities and achievements
   - Technologies and methodologies used
2. Normalize company names and titles:
   - Map to known entities when possible
   - Handle unknown or ambiguous entities
3. Structure experience information:
   - Create a hierarchical representation of experiences
   - Link skills to relevant experiences
   - Extract highlights and notable achievements

### Preference Extraction
1. Extract job preferences:
   - Work location preferences (remote, hybrid, on-site)
   - Geographical preferences
   - Industry preferences
   - Company size and culture preferences
   - Compensation expectations
2. Identify preference priorities:
   - Extract explicit statements about importance
   - Determine deal-breakers vs. nice-to-haves
   - Infer preference strength from context
3. Structure preference information:
   - Categorize by preference type
   - Assign importance levels
   - Include supporting context from the conversation

### Database Integration
1. Create functions to store extracted information:
   - Update candidate_skills table
   - Update candidate_preferences table
   - Store original transcript and extraction metadata
2. Implement merge logic for new information:
   - Compare with existing profile data
   - Handle conflicts and contradictions
   - Update confidence scores based on multiple sources
3. Provide traceability:
   - Link extracted data to specific transcript segments
   - Enable review and verification of extraction results

## Testing Requirements
1. Create unit tests for each extraction component
2. Develop integration tests for the complete pipeline
3. Create a test suite with diverse conversation scenarios:
   - Clear, straightforward responses
   - Ambiguous or indirect responses
   - Contradictory statements
   - Technical vs. non-technical conversations
4. Test with real-world transcripts from sample calls
5. Evaluate extraction accuracy against human-labeled data

## Acceptance Criteria
1. System correctly extracts at least 90% of explicitly stated skills
2. Experience information is structured with correct timeline and responsibilities
3. Preferences are correctly categorized with appropriate priority levels
4. Extraction results include confidence scores for verification
5. Information is correctly stored in the database with proper associations
6. Extraction pipeline processes transcripts within reasonable time limits
7. Integration with existing candidate profile systems is functional

- LLM API for content analysis
- Skill taxonomy and normalization system
- Database schema for storing extracted information
- Speech-to-text transcription service

```go
const extractionPrompt = `
You are an information extraction assistant. Analyze the following conversation 
between a job candidate and a recruiter assistant. Extract the candidate's skills, 
experience, and job preferences.

Conversation:
{{.Transcript}}

Extract the following information in JSON format:
{
  "skills": [
    {
      "name": "skill name",
      "proficiency": "stated or inferred level (beginner/intermediate/expert)",
      "years_experience": "stated or inferred duration",
      "confidence": "high/medium/low based on clarity of statement",
      "context": "relevant quote from transcript"
    }
  ],
  "experiences": [
    {
      "company": "company name",
      "role": "job title",
      "start_date": "YYYY-MM or approximate",
      "end_date": "YYYY-MM or 'present'",
      "responsibilities": "key responsibilities mentioned",
      "achievements": "notable achievements mentioned",
      "technologies": "technologies mentioned in this role",
      "confidence": "high/medium/low based on clarity of statement"
    }
  ],
  "preferences": [
    {
      "category": "location/industry/company_size/etc.",
      "value": "stated preference",
      "importance": "must-have/preferred/nice-to-have",
      "confidence": "high/medium/low based on clarity of statement",
      "context": "relevant quote from transcript"
    }
  ]
}
`
```
