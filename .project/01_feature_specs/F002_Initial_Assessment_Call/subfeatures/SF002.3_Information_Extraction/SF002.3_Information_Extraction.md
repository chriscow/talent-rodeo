# SF002.3: Information Extraction

## Overview
The Information Extraction subfeature is responsible for analyzing the audio and transcripts from candidate assessment calls to extract structured data about the candidate's skills, experience, preferences, and other relevant information. This extracted information is then organized, stored, and made available for job matching and further candidate interaction.

## Status
**Partially Implemented**

## Relationship to SF002.2 Subfeatures
This feature works closely with several subfeatures of SF002.2 Structured Conversation:

1. **SF002.2.1: Conversation Phase Definition System** - Information extraction requirements are specified per conversation phase in the JSON configuration.

2. **SF002.2.3: Information Extraction & Processing** - While SF002.2.3 handles real-time extraction during the conversation, SF002.3 performs comprehensive extraction from the complete transcript after the call, with more complex analysis and entity normalization.

3. **SF002.2.4: Error Recovery & Conversation Control** - Information gaps identified during extraction may influence error recovery strategies in future conversations.

The key difference is that SF002.2.3 operates in real-time during the conversation to guide the flow, while SF002.3 processes the complete transcript after the call concludes for comprehensive data extraction and profile enrichment.

## Detailed Requirements

### Transcript Generation
1. Record the full conversation during assessment calls (with proper consent)
2. Transcribe audio to text using speech-to-text technology
3. Maintain speaker attribution (system vs. candidate)
4. Include timestamps for all conversational turns
5. Format transcript to facilitate further NLP processing
6. Handle speech recognition errors and uncertainties
7. Store both raw audio and processed transcript

### Information Classification
1. Identify and categorize key information types:
   - Hard skills (programming languages, tools, technologies)
   - Soft skills (communication, teamwork, problem-solving)
   - Work experience (companies, roles, responsibilities, duration)
   - Education and certifications
   - Career accomplishments and projects
   - Job preferences (location, industry, role type, company size)
   - Salary expectations and requirements
   - Availability and timeline
2. Tag information with confidence scores
3. Distinguish between explicitly stated vs. inferred information
4. Identify contradictions or inconsistencies with existing candidate data

### Entity Extraction
1. Extract named entities from conversation:
   - Company names
   - Job titles
   - Technology names
   - Time periods
   - Locations
   - Certifications and degrees
   - Projects
2. Normalize extracted entities to standardized forms
3. Link entities to known databases (e.g., map extracted tech stack to standardized skill taxonomy)
4. Handle ambiguous or novel entities

### Information Structuring
1. Convert extracted information into standardized data structures
2. Associate attributes with appropriate entities
   - Skills with proficiency levels
   - Experience with durations and recency
   - Preferences with importance levels
3. Organize information hierarchically (primary skills vs. secondary skills)
4. Apply domain-specific rules for structuring candidates' experience
5. Generate summary of key findings from each conversation section

### Data Storage and Integration
1. Update candidate profile with newly extracted information
2. Merge new information with existing profile data
3. Handle conflicting information with resolution strategies
4. Maintain history of information sources and confidence levels
5. Flag gaps or areas needing further clarification

## User Experience
1. No direct user interface for candidates during extraction process
2. Optional post-call review for candidates to verify extracted information
3. Curated dashboard for recruiters showing key extracted insights
4. Visual highlighting of new or updated information in candidate profiles
5. Confidence indicators for extracted information

## Test Cases
1. **Basic Extraction**: Verify system can extract skills, experience, and preferences from clear statements
2. **Entity Recognition**: Verify system correctly identifies and normalizes entities like companies and technologies
3. **Ambiguity Handling**: Verify system appropriately handles ambiguous statements with confidence scores
4. **Contradiction Resolution**: Verify system flags contradictions between new information and existing profile
5. **Completeness Check**: Verify system identifies missing information for follow-up
6. **Format Handling**: Verify system handles various speech patterns and formats for expressing the same information
7. **Integration**: Verify extracted information is correctly stored in the candidate's profile

## Usage Examples

### Information Extraction Process
```go
func extractInformationFromTranscript(ctx context.Context, db *sql.DB, transcriptID int64) error {
    // Fetch the transcript
    transcript, err := getTranscriptByID(db, transcriptID)
    if err != nil {
        return fmt.Errorf("failed to get transcript: %w", err)
    }
    
    // Extract structured information
    extractionResult, err := extractStructuredInfo(ctx, transcript.FullTranscript)
    if err != nil {
        return fmt.Errorf("failed to extract information: %w", err)
    }
    
    // Process each category of extracted information
    if err := processExtractedSkills(ctx, db, transcript.AppointmentID, extractionResult.Skills); err != nil {
        log.Printf("Error processing skills: %v", err)
    }
    
    if err := processExtractedExperiences(ctx, db, transcript.AppointmentID, extractionResult.Experiences); err != nil {
        log.Printf("Error processing experiences: %v", err)
    }
    
    if err := processExtractedPreferences(ctx, db, transcript.AppointmentID, extractionResult.Preferences); err != nil {
        log.Printf("Error processing preferences: %v", err)
    }
    
    // Update the transcript with extraction summary
    if err := storeExtractionSummary(db, transcriptID, extractionResult.Summary); err != nil {
        return fmt.Errorf("failed to store extraction summary: %w", err)
    }
    
    return nil
}
```

### Entity Normalization Example
```go
func normalizeCompanyName(ctx context.Context, companyName string) (string, float64, error) {
    // Check for exact matches in company database
    exactMatch, err := findExactCompanyMatch(ctx, companyName)
    if err == nil {
        return exactMatch, 1.0, nil
    }
    
    // Try fuzzy matching
    fuzzyMatches, err := findFuzzyCompanyMatches(ctx, companyName)
    if err != nil {
        return companyName, 0.0, fmt.Errorf("company matching failed: %w", err)
    }
    
    // If we have a good match, use it
    if len(fuzzyMatches) > 0 && fuzzyMatches[0].Score > 0.8 {
        return fuzzyMatches[0].CompanyName, fuzzyMatches[0].Score, nil
    }
    
    // No good match, return original with low confidence
    return companyName, 0.3, nil
}
```

### Real-time to Post-processing Integration
```go
func mergeRealtimeWithPostProcessing(ctx context.Context, db *sql.DB, conversationID string, transcriptID int64) error {
    // Fetch real-time extracted data
    realtimeData, err := fetchRealtimeExtractedData(ctx, db, conversationID)
    if err != nil {
        return fmt.Errorf("failed to fetch real-time data: %w", err)
    }
    
    // Fetch post-processing extracted data
    postProcessData, err := fetchPostProcessedData(ctx, db, transcriptID)
    if err != nil {
        return fmt.Errorf("failed to fetch post-processed data: %w", err)
    }
    
    // Merge data with conflict resolution
    mergedData, conflicts := mergeExtractionResults(realtimeData, postProcessData)
    
    // Handle conflicts
    if len(conflicts) > 0 {
        if err := flagConflictsForReview(ctx, db, conversationID, conflicts); err != nil {
            log.Printf("Error flagging conflicts: %v", err)
        }
    }
    
    // Store final merged results
    if err := storeMergedResults(ctx, db, conversationID, transcriptID, mergedData); err != nil {
        return fmt.Errorf("failed to store merged results: %w", err)
    }
    
    return nil
}
```
