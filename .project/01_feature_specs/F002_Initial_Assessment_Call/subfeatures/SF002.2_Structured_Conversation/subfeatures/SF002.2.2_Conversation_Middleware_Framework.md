# SF002.2.2: Conversation Middleware Framework

## Overview
The Conversation Middleware Framework provides the execution engine for managing conversation flow. It implements the mechanics of conversation management through composable middleware components, with the Phase Manager middleware serving as the central coordinator for phase transitions and state management.

**Partially Implemented**

### Phase Manager Middleware

The `PhaseManager` middleware serves as the central coordinator for conversation flow, executing transitions based on signals from monitoring middleware components.

#### Core Responsibilities:
1. **Phase State Management**:
   - Track the current active conversation phase
   - Maintain phase history for context awareness
   - Store phase-specific metadata and progress
   - Load and validate phase configurations

2. **Transition Coordination**:
   - Process transition requests from monitoring middleware
   - Validate transitions against phase configuration
   - Execute approved transitions
   - Maintain transition request priority queue

3. **Context Management**:
   - Inject phase-specific prompts into conversation
   - Update conversation context during transitions
   - Provide phase information to other middleware
   - Track phase completion status

#### Implementation Pattern:

```go
type PhaseManager struct {
    phaseConfig     *PhaseConfig     // Configuration from Phase Definition System
    currentPhase    string           // Current active phase ID
    phaseHistory    []PhaseTransition // History of phase transitions
    transitionQueue []TransitionRequest // Priority queue of transition requests
    mu              sync.RWMutex    // Mutex for thread safety
}

type TransitionRequest struct {
    RequestedPhase string    // Requested phase (or "" for next phase)
    Reason         string    // Reason for the request
    Priority       int       // Priority level (1=highest)
    Timestamp      time.Time // When the request was made
}

func (m *PhaseManager) RequestTransition(tc minds.ThreadContext, request TransitionRequest) {
    m.mu.Lock()
    defer m.mu.Unlock()
    
    // Add to priority queue
    m.transitionQueue = append(m.transitionQueue, request)
    sort.Slice(m.transitionQueue, func(i, j int) bool {
        return m.transitionQueue[i].Priority < m.transitionQueue[j].Priority
    })
}

func (m *PhaseManager) processTransitionRequests(tc minds.ThreadContext) minds.ThreadContext {
    m.mu.Lock()
    if len(m.transitionQueue) == 0 {
        m.mu.Unlock()
        return tc
    }
    
    // Get highest priority request
    request := m.transitionQueue[0]
    m.transitionQueue = m.transitionQueue[1:]
    m.mu.Unlock()
    
    // Validate and execute transition
    if m.isTransitionValid(request) {
        tc = m.executeTransition(tc, request)
    }
    
    return tc
}
```

## Implementation Notes
1. The middleware framework must maintain thread safety for concurrent operations
2. Transition requests should be processed in strict priority order
3. Each middleware component should focus on a single responsibility
4. The Phase Manager must validate all transitions against configuration
5. Error handling should be robust and well-logged
6. Performance monitoring is essential for troubleshooting

```go
        _, err := m.cfg.DB.Exec(`

            m.cfg.ConversationID,
            m.cfg.RunID,
            lastMsg.Name,
            lastMsg.Content,
            time.Now(),

        }
```

### Middleware Chain Setup
```go
func setupConversationMiddleware(conversationID string, db *sql.DB, phaseConfig *PhaseConfig) minds.ThreadHandler {
    // Create base handler with the LLM provider
    handler := handlers.NewBasic(conversationID, llmProvider)
    
    // Add logging middleware
    handler.Use(ConversationLogger())
    
    // Add persistence middleware
    handler.Use(PersistMessage(PersistenceConfig{
        DB: db,
        ConversationID: conversationID,
    }))
    
    // Add phase management middleware
    handler.Use(PhaseManager(phaseConfig))
    
    // Add turn limiter middleware
    handler.Use(TurnLimiter(phaseConfig))
    
    // Add time tracking middleware
    handler.Use(TimeTracker(15 * time.Minute)) // 15-minute call limit
    
    // Add information extraction middleware
    handler.Use(InformationExtractor(phaseConfig.RequiredInformation))
    
    // Add error recovery middleware
    handler.Use(ErrorRecovery(3)) // Error threshold of 3
    
    // Add summarization middleware
    handler.Use(ConversationSummarizer(llmProvider, systemPrompt))
    
    return handler
}
```

### Custom Middleware Example
```go
type TurnLimiterMiddleware struct {
    maxTurns     map[string]int // Phase ID -> max turns
    currentTurns map[string]int // Phase ID -> current turn count
    phaseManager *PhaseManager
    mu           sync.RWMutex
}

func NewTurnLimiterMiddleware(phaseConfig *PhaseConfig) *TurnLimiterMiddleware {
    maxTurns := make(map[string]int)
    for _, phase := range phaseConfig.Phases {
        for _, transition := range phase.Transitions {
            if transition.Type == "turn_count" {
                maxTurns[phase.ID] = transition.MaxTurns
                break
            }
        }
    }
    
    return &TurnLimiterMiddleware{
        maxTurns:     maxTurns,
        currentTurns: make(map[string]int),
    }
}

func (m *TurnLimiterMiddleware) Wrap(next minds.ThreadHandler) minds.ThreadHandler {
    return minds.ThreadHandlerFunc(func(tc minds.ThreadContext, _ minds.ThreadHandler) (minds.ThreadContext, error) {
        // Get current phase from context
        currentPhase := getPhaseFromContext(tc)
        
        // Increment turn count for current phase
        m.mu.Lock()
        m.currentTurns[currentPhase]++
        currentCount := m.currentTurns[currentPhase]
        maxTurns := m.maxTurns[currentPhase]
        m.mu.Unlock()
        
        // Check if max turns reached
        if maxTurns > 0 && currentCount >= maxTurns {
            // Signal phase transition
            m.phaseManager.TransitionToNextPhase(tc)
            
            // Reset turn counter for the phase
            m.mu.Lock()
            m.currentTurns[currentPhase] = 0
            m.mu.Unlock()
            
            // Add system message about transition
            tc = tc.AppendMessages(minds.Message{
                Role: minds.RoleSystem,
                Content: fmt.Sprintf("Maximum turns (%d) reached for phase '%s'. Transitioning to next phase.", maxTurns, currentPhase),
            })
        }
        
        // Continue the middleware chain
        return next.HandleThread(tc, nil)
    })
}
```
