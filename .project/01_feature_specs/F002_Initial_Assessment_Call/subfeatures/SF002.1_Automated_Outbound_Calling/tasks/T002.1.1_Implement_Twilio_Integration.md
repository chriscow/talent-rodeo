# T002.1.1: Implement Phone Number Validation for Twilio Client

## Task Description
Add comprehensive phone number validation to the Twilio client to ensure proper formatting of international and domestic phone numbers before making outbound calls.

## Current Implementation Status
The current Twilio client in `internal/tasks/handlers/twilio_client.go` accepts phone numbers in any format without validation or standardization, which can lead to call failures for improperly formatted numbers.

## Specific Requirements

1. Add a new function to validate and format phone numbers to E.164 format (e.g., +12345678901):
   ```go
   // ValidateAndFormatPhoneNumber validates a phone number and formats it to E.164 standard
   // Returns the formatted number and a boolean indicating if it's valid
   func ValidateAndFormatPhoneNumber(phoneNumber string) (string, bool)
   ```

2. Include support for:
   - US/Canada numbers (with or without country code)
   - International numbers with country codes
   - Numbers with various separators (spaces, dashes, parentheses)

3. The function should:
   - Remove all non-digit characters except the leading '+'
   - Verify the number has between 8 and 15 digits (including country code)
   - Add the default country code (+1) if not specified for US/Canada numbers
   - Return an E.164 formatted string
   - Return false for invalid numbers

4. Update the `MakeCall` function to validate phone numbers before making calls:
   ```go
   func (c *RealTwilioClient) MakeCall(ctx context.Context, from, to, twiml string) (string, error) {
       // Validate and format the 'to' number
       formattedTo, valid := ValidateAndFormatPhoneNumber(to)
       if !valid {
           return "", fmt.Errorf("invalid 'to' phone number: %s", to)
       }
       
       // Rest of the function
   }
   ```

## Acceptance Criteria
1. The `ValidateAndFormatPhoneNumber` function correctly validates and formats:
   - "+1 (555) 123-4567" → "+15551234567" (valid)
   - "555-123-4567" → "+15551234567" (valid, adding default country code)
   - "+44 20 1234 5678" → "+442012345678" (valid international)
   - "12" → false (invalid, too short)
   - "abcdefghijk" → false (invalid, non-numeric)
   
2. The `MakeCall` function validates numbers before making calls
3. Invalid phone numbers result in appropriate error messages
4. Unit tests verify validation for various phone number formats

## Required Changes
1. Add the `ValidateAndFormatPhoneNumber` function to `internal/tasks/handlers/twilio_client.go`
2. Update the `MakeCall` function to use the validation function
3. Add unit tests for the validation function

## Dependencies
- Existing Twilio client in `internal/tasks/handlers/twilio_client.go`
- Regular expression support (standard library)
