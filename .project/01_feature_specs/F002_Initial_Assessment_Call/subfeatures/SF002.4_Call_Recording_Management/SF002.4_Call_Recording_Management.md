# SF002.4: Call Recording Management

## Overview
The Call Recording Management subfeature enables the secure recording, storage, and transcription of assessment calls. With proper candidate consent, this feature captures audio from both parties during the conversation, securely stores these recordings, and transcribes them to text for later analysis, quality assurance, and information extraction.

## Status
**Not Implemented**

## Detailed Requirements

### Recording Functionality
1. Capture audio from both the candidate and the AI system during calls
2. Support recording of calls of varying durations (typically 15-30 minutes)
3. Handle recording start/stop at appropriate moments
4. Apply real-time audio processing for quality improvement
5. Ensure minimal latency impact on the conversation
6. Implement failsafe mechanisms for recording interruptions

### Consent Management
1. Provide clear recording disclosures before calls begin
2. Obtain explicit consent from candidates before recording
3. Offer options to opt-out of recording while continuing the call
4. Store consent records with timestamps for compliance
5. Implement periodic reminders that recording is in progress
6. Allow for consent revocation and recording deletion

### Secure Storage
1. Encrypt all audio recordings in transit and at rest
2. Establish secure storage infrastructure with appropriate access controls
3. Implement retention policies with automatic expiration
4. Create backup protocols for disaster recovery
5. Maintain audit trails of all access to recordings
6. Comply with relevant data protection regulations

### Transcription Processing
1. Convert audio recordings to text using speech-to-text technology
2. Support speaker differentiation (candidate vs. AI)
3. Include timestamps throughout transcripts
4. Handle accents, technical terminology, and industry jargon
5. Implement error correction for transcription inaccuracies
6. Store transcripts securely with links to original recordings

### Access Control
1. Restrict recording access to authorized personnel only
2. Implement role-based permissions for different levels of access
3. Provide secure methods for reviewers to access recordings
4. Log all access attempts and actions taken
5. Support secure sharing for authorized quality reviews
6. Implement time-limited access tokens for external reviewers

## User Experience
1. Transparency about recording purpose and practices
2. Clear opt-in process with minimal friction
3. No noticeable impact on call quality during recording
4. Optional access to own recording for candidates
5. Non-intrusive recording process that doesn't distract from conversation

## Test Cases
1. **Consent Capture**: Verify system properly captures and stores consent
2. **Recording Quality**: Verify audio quality meets standards for transcription
3. **Storage Security**: Verify recordings are properly encrypted and secured
4. **Transcription Accuracy**: Verify speech-to-text conversion meets accuracy requirements
5. **Access Controls**: Verify only authorized users can access recordings
6. **Retention Policies**: Verify automatic expiration functions correctly
7. **Performance Impact**: Verify recording has minimal impact on call performance

   - Current implementation stores recordings in ulaw format with metadata

   - Recording initialization happens in `internal/voice/session.go`
   - Automatically creates timestamped recording files
   - Sets up recording directory

### Extending for Full Compliance

To fully implement this spec, developers should extend the existing implementation with:

1. **Consent Management**
   - Add consent flags to the database schema (already included in the `appointments` table)
   - Pass consent information to the Session constructor
   - Add consent verification before recording initialization

2. **Secure Storage**
   - Implement encryption for the recording files
   - Update the storage location to use secure cloud storage
   - Implement retention policies

3. **Access Control**
   - Implement the `recording_access_logs` table as specified
   - Create endpoints for authorized access to recordings
   - Add role-based access control

4. **Transcription Integration**
   - Leverage OpenAI's transcription capabilities from the realtime API
   - Store transcripts in the `appointments.transcript` field
   - Generate summaries as specified

The existing implementation provides a solid foundation that already handles the core recording functionality, making it straightforward to implement the remaining requirements for a fully compliant call recording system.

## Usage Examples

### Recording Initialization Example
```go
func initializeCallRecording(ctx context.Context, callSID string, userID int64) (*RecordingSession, error) {
    // Check for consent first
    hasConsent, err := checkRecordingConsent(ctx, userID)
    if err != nil {
        return nil, fmt.Errorf("failed to check recording consent: %w", err)
    }
    
    if !hasConsent {
        return nil, errors.New("recording consent not provided")
    }
    
    // Initialize recording with telephony provider
    recordingParams := map[string]string{
        "callSid": callSID,
        "recordingStatusCallback": config.RecordingCallbackURL,
        "recordingStatusCallbackEvent": "in-progress completed absent failed",
    }
    
    recordingResult, err := telephonyClient.Recordings.Create(recordingParams)
    if err != nil {
        return nil, fmt.Errorf("failed to initialize recording: %w", err)
    }
    
    // Create recording session in database
    session := &RecordingSession{
        CallSID:         callSID,
        UserID:          userID,
        RecordingSID:    recordingResult.Sid,
        Status:          "in-progress",
        StartTimestamp:  time.Now(),
    }
    
    if err := storeRecordingSession(ctx, session); err != nil {
        return nil, fmt.Errorf("failed to store recording session: %w", err)
    }
    
    // Log recording initiation
    if err := logRecordingEvent(ctx, callSID, "recording_initiated", userID); err != nil {
        log.Printf("Warning: Failed to log recording event: %v", err)
    }
    
    return session, nil
}
```

### Transcription Processing Example
```go
func processRecordingTranscription(ctx context.Context, recordingSID string, recordingURL string) error {
    // Download recording from storage
    audioData, err := downloadRecording(recordingURL)
    if err != nil {
        return fmt.Errorf("failed to download recording: %w", err)
    }
    
    // Send to speech-to-text service
    transcriptionParams := &TranscriptionRequest{
        AudioData:      audioData,
        LanguageCode:   "en-US",
        EnableSpeakerDiarization: true,
        MinSpeakerCount: 2,
        MaxSpeakerCount: 2,
    }
    
    transcriptionResult, err := speechToTextClient.Transcribe(ctx, transcriptionParams)
    if err != nil {
        return fmt.Errorf("failed to transcribe recording: %w", err)
    }
    
    // Process and structure the transcript
    structuredTranscript, err := structureTranscript(transcriptionResult)
    if err != nil {
        return fmt.Errorf("failed to structure transcript: %w", err)
    }
    
    // Store transcript in database
    if err := storeTranscript(ctx, recordingSID, structuredTranscript); err != nil {
        return fmt.Errorf("failed to store transcript: %w", err)
    }
    
    // Generate transcript summary
    summary, err := generateTranscriptSummary(ctx, structuredTranscript)
    if err != nil {
        log.Printf("Warning: Failed to generate transcript summary: %v", err)
    } else {
        if err := storeTranscriptSummary(ctx, recordingSID, summary); err != nil {
            log.Printf("Warning: Failed to store transcript summary: %v", err)
        }
    }
    
    // Trigger information extraction process
    if err := triggerInformationExtraction(ctx, recordingSID); err != nil {
        log.Printf("Warning: Failed to trigger information extraction: %v", err)
    }
    
    return nil
}
```

### Access Control Example
```go
func authorizeRecordingAccess(ctx context.Context, userID int64, recordingID int64, accessType string) (bool, error) {
    // Get user role
    user, err := getUserWithRoles(ctx, userID)
    if err != nil {
        return false, fmt.Errorf("failed to get user roles: %w", err)
    }
    
    // Check if user has appropriate role for access
    hasAccess := false
    requiredRoles := map[string][]string{
        "view": {"admin", "recruiter", "quality_analyst"},
        "download": {"admin", "quality_analyst"},
        "delete": {"admin"},
    }
    
    if requiredRolesForAccess, exists := requiredRoles[accessType]; exists {
        for _, role := range user.Roles {
            for _, requiredRole := range requiredRolesForAccess {
                if role == requiredRole {
                    hasAccess = true
                    break
                }
            }
            if hasAccess {
                break
            }
        }
    }
    
    if !hasAccess {
        return false, nil
    }
    
    // Check if recording belongs to a candidate assigned to this recruiter
    if user.Role == "recruiter" {
        isAssigned, err := isCandidateAssignedToRecruiter(ctx, recordingID, userID)
        if err != nil {
            return false, fmt.Errorf("failed to check candidate assignment: %w", err)
        }
        if !isAssigned {
            return false, nil
        }
    }
    
    // Log access attempt
    accessLog := &RecordingAccessLog{
        RecordingID:     recordingID,
        UserID:          userID,
        AccessType:      accessType,
        AccessTimestamp: time.Now(),
        AccessIP:        getClientIP(ctx),
        AccessReason:    getReason(ctx),
    }
    
    if err := logRecordingAccess(ctx, accessLog); err != nil {
        log.Printf("Warning: Failed to log recording access: %v", err)
    }
    
    return true, nil
}
``` 
