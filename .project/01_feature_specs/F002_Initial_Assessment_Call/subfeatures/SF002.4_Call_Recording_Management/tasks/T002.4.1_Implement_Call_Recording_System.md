# T002.4.1: Implement Call Recording System

## Task Description
Implement a comprehensive call recording system for the Initial Assessment Call feature that securely captures, stores, and manages audio recordings of candidate interviews. This task involves integrating with the telephony provider, implementing secure storage, and creating the necessary management interfaces for recorded calls.

## Project Context
Talent Rodeo's Initial Assessment Call feature (F002) enables automated phone interviews with candidates. Recording these calls (with proper consent) is critical for quality assurance, training, and information extraction. The Call Recording Management subfeature (SF002.4) is currently not implemented, although the database schema is in place with fields for call_sid, transcript, and transcript_summary in the appointments table.

Example of recording download and storage:
```go
func downloadAndStoreRecording(ctx context.Context, recordingSID, recordingURL string) (string, error) {
    // Download recording from Twilio
    resp, err := http.Get(recordingURL)
    if err != nil {
        return "", fmt.Errorf("failed to download recording: %w", err)
    }
    defer resp.Body.Close()

    // Generate storage path
    storagePath := fmt.Sprintf("recordings/%s/%s.wav", time.Now().Format("2006/01/02"), recordingSID)

    // Upload to cloud storage
    storageClient, err := storage.NewClient(ctx)
    if err != nil {
        return "", fmt.Errorf("failed to create storage client: %w", err)
    }
    defer storageClient.Close()

    bucket := storageClient.Bucket(recordingsBucket)
    obj := bucket.Object(storagePath)
    w := obj.NewWriter(ctx)
    
    // Set appropriate content type and metadata
    w.ContentType = "audio/wav"
    w.Metadata = map[string]string{
        "recording_sid": recordingSID,
        "created_at":    time.Now().Format(time.RFC3339),
    }

    // Copy recording to storage
    if _, err := io.Copy(w, resp.Body); err != nil {
        return "", fmt.Errorf("failed to copy recording to storage: %w", err)
    }
    
    // Close writer (finalizes upload)
    if err := w.Close(); err != nil {
        return "", fmt.Errorf("failed to finalize recording upload: %w", err)
    }

    return storagePath, nil
}
```
