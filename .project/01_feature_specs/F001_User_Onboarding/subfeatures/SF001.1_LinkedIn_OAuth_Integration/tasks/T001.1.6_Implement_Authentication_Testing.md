# T001.1.6: Implement Authentication Testing

## Task Description
Implement comprehensive testing for the LinkedIn OAuth authentication flow to ensure reliability and security. This task includes creating unit tests, integration tests, and end-to-end tests to verify the entire authentication process, error handling, and session management.

## Implementation Details

### Unit Testing
1. Create unit tests for the authentication provider:
   - Test provider configuration
   - Test session creation
   - Test user creation from profile data
   
2. Create unit tests for session management:
   - Test session creation
   - Test session validation
   - Test session expiration
   - Test session termination

### Integration Testing
1. Implement tests for the authentication flow:
   - Test authentication initiation
   - Test callback handling
   - Test error handling
   
2. Create tests for user management:
   - Test new user creation
   - Test existing user updates
   - Test creating candidate records

### End-to-End Testing
1. Implement browser-based tests for the complete authentication flow:
   - Test the login button
   - Test authentication redirects
   - Test successful authentication
   - Test authentication errors
   - Test session persistence
   - Test logout functionality
   
2. Create mocks for LinkedIn OAuth API:
   - Mock OAuth provider responses
   - Mock user profile data
   - Simulate error conditions

### Test Environment Configuration
1. Set up testing environment variables:
   - Configure test OAuth credentials
   - Set up test database
   - Configure test URLs and endpoints
   
2. Implement test helpers and utilities:
   - Create authentication test fixtures
   - Implement test session helpers
   - Create mock HTTP handlers

## Acceptance Criteria
1. All authentication components have unit test coverage
2. Integration tests verify the complete authentication flow
3. End-to-end tests validate the user experience
4. Tests cover both success and error scenarios
5. Test suite can be run consistently and reliably
6. All tests pass with the current implementation

Example authentication handler test in `cmd/web/handlers.auth_test.go`:

```go
func TestCompleteSocialAuth(t *testing.T) {
    app := newTestApplication(t)
    ts := newTestServer(t, app.routes())
    defer ts.Close()

    // Set up test cases
    tests := []struct {
        name       string
        urlParams  string
        wantCode   int
        wantHeader string
    }{
        {
            name:      "OAuth Error",
            urlParams: "?error=access_denied&error_description=User+denied+access",
            wantCode:  http.StatusUnauthorized,
        },
        {
            name:       "Successful Auth",
            urlParams:  "", // No error params
            wantCode:   http.StatusFound,
            wantHeader: "/profile", // Should redirect to profile
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // Set up mock Gothic complete user auth
            gothic.CompleteUserAuthFunc = func(res http.ResponseWriter, req *http.Request) (goth.User, error) {
                if strings.Contains(req.URL.RawQuery, "error=") {
                    return goth.User{}, errors.New("user denied access")
                }
                
                return goth.User{
                    UserID:      "123456789",
                    Name:        "Test User",
                    Email:       "test@example.com",
                    Provider:    "linkedin",
                    FirstName:   "Test",
                    LastName:    "User",
                }, nil
            }

            // Make request
            code, header := ts.requestWithCookies("GET", "/auth/linkedin/callback"+tt.urlParams, nil)
            
            // Check status code
            if code != tt.wantCode {
                t.Errorf("want %d; got %d", tt.wantCode, code)
            }
            
            // Check redirect if expected
            if tt.wantHeader != "" && !strings.Contains(header.Get("Location"), tt.wantHeader) {
                t.Errorf("want location header to contain %q; got %q", tt.wantHeader, header.Get("Location"))
            }
        })
    }
}
```
