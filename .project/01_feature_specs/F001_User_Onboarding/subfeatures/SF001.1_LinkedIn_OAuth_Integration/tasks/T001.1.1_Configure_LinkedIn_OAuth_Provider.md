# T001.1.1: Configure LinkedIn OAuth Provider

## Task Description
Set up and configure the LinkedIn OAuth provider to enable authentication via LinkedIn for the Talent Rodeo platform. This task involves creating the necessary provider configurations, implementing authentication endpoints, and establishing the OAuth flow.

## Implementation Details

### Provider Configuration
1. Implement the LinkedIn OAuth provider using the Goth library
2. Configure the provider with the appropriate client key, secret, and callback URL
3. Set up the required OAuth scopes:
   - `openid` - For OpenID Connect functionality
   - `profile` - For basic profile information
   - `email` - For email address access
4. Create provider initialization in the application startup code

### Environment Configuration
1. Add environment variables to store LinkedIn OAuth credentials:
   - `LINKEDIN_KEY` - The LinkedIn application client ID
   - `LINKEDIN_SECRET` - The LinkedIn application client secret
   - `LINKEDIN_CALLBACK_URL` - The callback URL for LinkedIn OAuth
2. Update configuration loading to retrieve these values
3. Document the required environment variables in the README and .env template

## Acceptance Criteria
1. LinkedIn OAuth provider is properly configured
2. Application can be started with valid LinkedIn OAuth credentials
3. Provider is initialized during application startup
4. Configuration is secure and doesn't expose credentials in the code

## Dependencies
- Go OAuth2 library
- Goth social authentication library
- Environment configuration system

## Estimated Effort
4 hours

## References

### Code References
The LinkedIn OAuth provider is implemented in:
```go
// internal/auth/linkedin.go
func New(clientKey, secret, callbackURL string, scopes ...string) *Provider {
    p := &Provider{
        ClientKey:    clientKey,
        Secret:       secret,
        CallbackURL:  callbackURL,
        providerName: "linkedin",
    }
    p.config = newConfig(p, scopes)
    return p
}
```

The provider initialization should occur in the application startup, similar to:
```go
// cmd/web/main.go
goth.UseProviders(
    auth.New(
        os.Getenv("LINKEDIN_KEY"),
        os.Getenv("LINKEDIN_SECRET"),
        os.Getenv("LINKEDIN_CALLBACK_URL"),
        "openid", "profile", "email",
    ),
)
```
