# T001.1.4: Implement User Session Management

## Task Description
Implement secure session management for users authenticated via LinkedIn OAuth. This task includes creating, maintaining, and terminating user sessions, implementing appropriate security measures, and ensuring a seamless user experience throughout the authentication lifecycle.

## Implementation Details

### Session Creation
1. Create secure sessions after successful authentication:
   - Set up session with user ID and other essential data
   - Configure appropriate session duration
   - Store session data securely
   
2. Implement secure cookie handling:
   - Use HTTP-only cookies
   - Apply appropriate Same-Site restrictions
   - Set secure flag in production environments
   - Configure appropriate expiration times

### Session Management
1. Implement middleware to extract and validate sessions on each request:
   - Retrieve user data based on session information
   - Add authenticated user to request context
   - Validate session expiration and integrity
   
2. Handle session renewal and expiration:
   - Implement session refresh mechanism
   - Handle expired sessions gracefully
   - Provide clear feedback when sessions expire

### Logout Functionality
1. Implement secure logout process:
   - Clear session data
   - Expire session cookies
   - Provide appropriate redirect after logout
   
2. Handle edge cases:
   - Multiple devices/browsers
   - Invalid or already expired sessions

## Acceptance Criteria
1. Authenticated users receive a secure session
2. Sessions persist across page loads
3. Session data is stored securely (not exposed to client-side code)
4. Users can successfully log out of the application
5. Sessions expire after the configured timeout period
6. Security best practices are followed for cookie handling

## Dependencies
- LinkedIn OAuth authentication flow (T001.1.2)
- User creation from LinkedIn profile (T001.1.3)
- Cookie management utilities
- Session storage implementation

```go
func (app *application) logoutUser(w http.ResponseWriter, r *http.Request) {
    session, err := app.sessionStore.Get(r, "session")
    if err != nil {
        app.serverError(w, r, err)
        return
    }

    // Clear all session values
    for key := range session.Values {
        delete(session.Values, key)
    }

    // Set MaxAge to -1 to expire the cookie immediately
    session.Options.MaxAge = -1

    // Save the session
    err = session.Save(r, w)
    if err != nil {
        app.serverError(w, r, err)
        return
    }

    // Redirect to login page
    http.Redirect(w, r, "/auth/linkedin", http.StatusFound)
}
```

Authentication middleware in `cmd/web/middleware.go`:

```go
func (app *application) authenticate(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // Check for existing session
        session, err := app.sessionStore.Get(r, "session")
        if err != nil {
            next.ServeHTTP(w, r)
            return
        }
        
        // Get user ID from session
        if userID, ok := session.Values["UserID"].(int64); ok {
            user, err := app.db.GetUser(userID)
            if err == nil {
                // Add user to request context
                r = contextSetAuthenticatedUser(r, user)
            }
        }
        
        next.ServeHTTP(w, r)
    })
}
```
