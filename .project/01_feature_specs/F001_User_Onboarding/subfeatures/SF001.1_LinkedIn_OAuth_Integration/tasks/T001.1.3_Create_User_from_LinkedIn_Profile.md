# T001.1.3: Create User from LinkedIn Profile

## Task Description
Implement functionality to create or update a user record in the database using the profile information received from LinkedIn during authentication. This task includes mapping LinkedIn profile data to our user model, handling new user creation, and updating existing users.

## Implementation Details

### Data Processing
1. Extract and validate required profile information from LinkedIn:
   - Email address (required, used as unique identifier)
   - First name (required)
   - Last name (required)
   - Full name (required)
   - Profile picture URL (optional)
   - LinkedIn user ID (required, stored but not displayed)
   
2. Map LinkedIn profile data to the Talent Rodeo user model
3. Validate that all required fields are present before user creation

### User Management
1. Implement logic to check if a user with the given email already exists
2. For new users:
   - Create a user record with LinkedIn profile data
   - Set appropriate default values for missing fields
   - Set initial onboarding state
   - Create associated candidate record
   
3. For existing users:
   - Update the user record with any new LinkedIn profile information
   - Maintain existing user data not provided by LinkedIn

### Database Operations
1. Implement database functions to:
   - Look up users by email address
   - Create new user records from LinkedIn data
   - Update existing user records with LinkedIn data
   
2. Ensure appropriate error handling for database operations
3. Use transactions where necessary to maintain data integrity

## Acceptance Criteria
1. System can create new users using LinkedIn profile data
2. System can identify and update existing users
3. All required user data is validated before record creation
4. Database transactions maintain data integrity
5. Appropriate error handling for database operations

## Dependencies
- LinkedIn OAuth authentication flow (T001.1.2)
- Database schema for users and candidates
- Data validation utilities

func (db *DB) NewUserFromGothUser(gothUser goth.User, role string) (*User, error) {
    user := User{
        Email:       gothUser.Email,
        Provider:    gothUser.Provider,
        Name:        gothUser.Name,
        FirstName:   gothUser.FirstName,
        LastName:    gothUser.LastName,
        NickName:    gothUser.NickName,
        Description: gothUser.Description,
        UserID:      gothUser.UserID,
        AvatarURL:   gothUser.AvatarURL,
        Location:    gothUser.Location,
        Role:        &role,
    }

    id, err := db.InsertUser(user)
    if err != nil {
        return nil, err
    }

    user.ID = id
    return &user, nil
}

// Look up existing user by email
func (db *DB) GetUserByEmail(email string) (*User, bool, error) {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    query := `SELECT * FROM users WHERE email = $1`
    var user User
    err := db.Get(&user, query, email)
    if err != nil {
        if err == sql.ErrNoRows {
            return nil, false, nil
        }
        return nil, false, err
    }

    return &user, true, nil
}
