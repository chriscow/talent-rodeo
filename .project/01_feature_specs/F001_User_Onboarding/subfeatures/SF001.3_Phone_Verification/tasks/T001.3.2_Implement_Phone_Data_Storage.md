# T001.3.2: Implement Phone Data Storage

## Description
Implement secure and efficient storage of user phone numbers in the database, ensuring proper formatting, access controls, and integration with the user profile system. This task involves database operations, data formatting, and ensuring proper association with user accounts.

## Implementation Details

### Database Schema
- Ensure the users table has a nullable `phone` column of TEXT type
- Document the phone number format (E.164 recommended: +12345678901)
- Consider indexing for potential future queries by phone number

### Data Operations
- Create a database function to update user phone numbers
- Implement proper parameter sanitization to prevent SQL injection
- Add transaction support for data integrity
- Handle NULL values appropriately for users without phone numbers

### Security and Privacy
- Implement appropriate access controls for phone number data
- Ensure phone numbers are only accessible to authorized system components
- Log access to phone number data for audit purposes
- Consider data minimization principles when displaying phone numbers in UI

### Integration
- Update the user struct to include the phone number field
- Integrate phone storage with the onboarding process
- Ensure phone number updates trigger appropriate onboarding state changes
- Provide functions to validate phone existence before operations that require it

## Acceptance Criteria
- Phone numbers are correctly stored in the database with consistent formatting
- Phone numbers are properly associated with the correct user accounts
- Database operations handle both setting and clearing phone numbers
- Appropriate error handling for database operations
- Updates to phone numbers are atomic and maintain data integrity
- Phone number storage respects privacy and security requirements

## Dependencies
- Database schema with phone column
- Database connection and transaction handling
- Phone number formatting utilities
- User authentication and authorization system

### Database Operations
```go
// UpdateUserPhone updates the user's phone number in the database
func (db *DB) UpdateUserPhone(userID int, phone string) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    var phonePtr *string
    if phone != "" {
        // Format phone to E.164 before storage
        formattedPhone := formatPhoneToE164(phone)
        phonePtr = &formattedPhone
    }

    query := `UPDATE users SET phone = $1 WHERE id = $2`
    _, err := db.ExecContext(ctx, query, phonePtr, userID)
    return err
}

// GetUserPhone retrieves a user's phone number
func (db *DB) GetUserPhone(userID int) (string, bool, error) {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    var phone sql.NullString
    query := `SELECT phone FROM users WHERE id = $1`
    err := db.QueryRowContext(ctx, query, userID).Scan(&phone)
    
    if err != nil {
        if err == sql.ErrNoRows {
            return "", false, nil
        }
        return "", false, err
    }
    
    if !phone.Valid {
        return "", false, nil
    }
    
    return phone.String, true, nil
}
```
