# T001.4.2: Implement Profile Enhancement with Resume

## Description
Implement functionality to enhance a user's profile with data extracted from their uploaded resume. This task involves updating the user record with resume content, extracting skills and experience information, and updating the onboarding state to reflect the completed resume upload step.

## Implementation Details

### Resume Data Integration
- Update the user record with:
  - Resume filename for reference
  - Full resume text content
  - Summarized resume content (if available)
- Ensure proper encoding and storage of potentially large text content
- Handle update operations to avoid data loss

### Skill Extraction
- Analyze resume text to identify skills and technologies
- Create skill records associated with the candidate
- Set initial confidence and experience levels based on resume content
- Store extracted skills in the database
- Handle duplicates and variations of similar skills

### Onboarding State Update
- Update the user's onboarding state to `resume_uploaded`
- Record timestamp for this state transition
- Update any related onboarding progress indicators
- Prepare for next onboarding steps

### Data Validation
- Validate that resume text is properly extracted and not empty
- Ensure skills extraction produces meaningful results
- Verify that all database constraints are met
- Implement appropriate error handling for extraction failures

## Acceptance Criteria
- User records are updated with resume filename and content
- Skills are extracted from the resume and stored in the database
- Onboarding state is correctly updated to `resume_uploaded`
- Data consistency is maintained across all updates
- Skills extraction produces relevant and accurate results
- Error conditions are handled appropriately
- Updates are performed efficiently even with large resume texts

## Dependencies
- Resume upload and text extraction feature
- Database schema for users, candidates, and skills
- Skill extraction algorithm
- Onboarding state management

## Estimated Effort
5 hours

// Update user profile with resume data
func (app *application) updateUserResume(user *database.User, fileName, resumeText string) error {
    if err := app.db.UpdateFullResume(user.ID, fileName, resumeText); err != nil {
        return fmt.Errorf("failed to save resume: %w", err)
    }
    
    // Update user object with new resume data
    user.FullResume = &resumeText
    user.ResumeFilename = &fileName
    
    // Update onboarding state
    if err := app.db.UpdateOnboardingStep(user.ID, onboarding.StepResumeUploaded); err != nil {
        return fmt.Errorf("failed to update onboarding state: %w", err)
    }
    
    return nil
}

// Extract and store skills from resume
func (app *application) processResumeSkills(r *http.Request, user *database.User, resumeText string) error {
    candidate, err := app.db.GetCandidateByUserID(user.ID)
    if err != nil {
        return fmt.Errorf("failed to get candidate: %w", err)
    }
    
    // Extract skills from resume text
    skills, err := app.skillExtractor.ExtractSkills(resumeText)
    if err != nil {
        app.logger.Error("Failed to extract skills", "error", err)
        return fmt.Errorf("failed to extract skills: %w", err)
    }
    
    // Store each extracted skill
    for _, skill := range skills {
        err := app.db.UpsertCandidateSkill(candidate.ID, &database.CandidateSkill{
            Name:       skill.Name,
            Level:      skill.Level,
            YearsUsed:  skill.YearsUsed,
            Confidence: skill.Confidence,
            Summary:    skill.Summary,
        })
        
        if err != nil {
            app.logger.Error("Failed to store skill", "skill", skill.Name, "error", err)
            // Continue with other skills even if one fails
            continue
        }
    }
    
    return nil
}

### Database Operations
```go
// UpdateFullResume updates the user's resume information
func (db *DB) UpdateFullResume(userID int, fileName, resume string) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    query := `
        UPDATE users 
        SET resume_filename = $1, full_resume = $2, updated_at = NOW() 
        WHERE id = $3
    `
    
    _, err := db.ExecContext(ctx, query, fileName, resume, userID)
    return err
}

// UpsertCandidateSkill adds or updates a skill for a candidate
func (db *DB) UpsertCandidateSkill(candidateID uuid.UUID, skill *CandidateSkill) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()
    
    query := `
        INSERT INTO candidate_skills 
        (candidate_id, name, level, years_used, confidence, summary) 
        VALUES ($1, $2, $3, $4, $5, $6)
        ON CONFLICT (candidate_id, name) DO UPDATE
        SET level = $3, years_used = $4, confidence = $5, summary = $6,
            updated_at = NOW()
        RETURNING id
    `
    
    var id uuid.UUID
    err := db.QueryRowContext(
        ctx, query, 
        candidateID, skill.Name, skill.Level, 
        skill.YearsUsed, skill.Confidence, skill.Summary,
    ).Scan(&id)
    
    if err != nil {
        return fmt.Errorf("failed to upsert skill: %w", err)
    }
    
    skill.ID = id
    return nil
}
```
