# SF001.4: Basic Profile Creation

## Overview
The Basic Profile Creation subfeature combines data from LinkedIn authentication and the uploaded resume to create a comprehensive user profile. This profile serves as the foundation for all subsequent system features, including skill extraction, job matching, and document customization.

## Status
**Implemented**

## Detailed Requirements

### Profile Data Sources
1. LinkedIn Authentication Data:
   - Name (first, last, full)
   - Email address (primary identifier)
   - Profile picture URL
   - LinkedIn user ID
   - Location (if available)
2. Resume Upload Data:
   - Resume text content
   - Resume summary
   - Extracted skills and experience
   - Contact information
3. User-Provided Data:
   - Phone number
   - Additional preferences collected during onboarding

### Profile Creation Process
1. Initial profile creation upon LinkedIn authentication:
   - Create user record with LinkedIn basic data
   - Set onboarding state to 'initial'
   - Create associated candidate record
2. Profile enhancement after resume upload:
   - Add resume text and filename to profile
   - Add phone number to profile
   - Update onboarding state to 'resume_uploaded'
   - Extract and store skills from resume
3. Onboarding state progression:
   - Track user's progress through onboarding steps
   - Update state at each completed step
   - Store timestamps for step completion

### Data Model Requirements
1. User Information:
   - Unique identifier (database-generated)
   - Authentication information
   - Personal information (name, email, phone)
   - Resume data (text, filename)
   - Onboarding state tracking
2. Candidate Information:
   - Extended profile for job-seeking functionality
   - Link to user record
   - Preferences and customizations
3. Skills Information:
   - Extracted skills from resume
   - Skill ratings and experience levels
   - User-confirmed skill preferences

### Onboarding State Management
1. Define clear onboarding steps:
   - initial (account created)
   - resume_uploaded (resume and phone provided)
   - phone_call_scheduled (assessment call time selected)
   - phone_call_completed (assessment call finished)
   - preferences_extracted (job preferences established)
   - job_search_started (initial job search performed)
2. Track state transitions with timestamps
3. Direct user flow based on current onboarding state
4. Allow for non-linear completion when appropriate

## User Experience
1. Provide clear indication of onboarding progress
2. Direct users to appropriate next steps based on their current state
3. Allow users to review and confirm extracted profile information
4. Enable profile editing for corrections when needed
5. Present a cohesive flow throughout the onboarding process

## Usage Examples

### Onboarding State Management Example
```go
// Define onboarding steps
const (
    StepInitial            = "initial"
    StepResumeUploaded     = "resume_uploaded"
    StepPhoneCallScheduled = "phone_call_scheduled"
    StepPhoneCallCompleted = "phone_call_completed"
    StepPreferencesExtracted = "preferences_extracted"
    StepJobSearchStarted   = "job_search_started"
)

// Update onboarding state
func updateOnboardingStep(db *sql.DB, userID int64, step string) error {
    query := `
        UPDATE users 
        SET onboarding_step = $1, 
            onboarding_step_updated_at = CURRENT_TIMESTAMP
        WHERE id = $2
    `
    _, err := db.Exec(query, step, userID)
    return err
}

// Create new user from LinkedIn data
func createUserFromLinkedIn(db *sql.DB, data *LinkedInUserData) (*User, error) {
    // Insert user data
    query := `
        INSERT INTO users (
            email, provider, name, first_name, last_name,
            user_id, avatar_url, onboarding_started_at, onboarding_step
        ) VALUES ($1, $2, $3, $4, $5, $6, $7, CURRENT_TIMESTAMP, $8)
        RETURNING id
    `
    
    var userID int64
    err := db.QueryRow(
        query,
        data.Email, "linkedin", data.Name,
        data.FirstName, data.LastName,
        data.UserID, data.AvatarURL, StepInitial,
    ).Scan(&userID)
    
    if err != nil {
        return nil, err
    }
    
    // Create candidate record
    createCandidateQuery := `
        INSERT INTO candidates (user_id)
        VALUES ($1)
    `
    _, err = db.Exec(createCandidateQuery, userID)
    if err != nil {
        return nil, err
    }
    
    // Return complete user object
    return getUserByID(db, userID)
}
```

### Profile Page Routing Example
```go
func showProfilePage(w http.ResponseWriter, r *http.Request) {
    user := getUserFromContext(r)
    
    // Get current onboarding state
    state, err := getOnboardingState(db, user.ID)
    if err != nil {
        renderError(w, "Failed to get onboarding state")
        return
    }
    
    // Show appropriate view based on onboarding state
    switch state.CurrentStep {
    case "initial":
        renderTemplate(w, "profile-resume-upload.html", user)
    case "resume_uploaded":
        renderTemplate(w, "profile-schedule-phone-call.html", user)
    case "phone_call_scheduled":
        renderTemplate(w, "profile-waiting-call.html", user)
    case "phone_call_completed":
        renderTemplate(w, "profile-preferences.html", user)
    case "preferences_extracted":
        renderTemplate(w, "profile-job-search.html", user)
    case "job_search_started":
        renderTemplate(w, "profile-jobs.html", user)
    default:
        renderTemplate(w, "profile.html", user)
    }
}
```
