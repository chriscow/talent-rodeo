# Task: Implement Resume Upload UI

## Description
Design and implement the user interface components for the resume upload feature. This includes HTML templates, CSS styling, and client-side validation for a clean, responsive, and user-friendly resume upload experience.

## Implementation Details

### Page Templates
- Create the main resume upload page template
- Implement the resume upload form partial template
- Design error message display components
- Ensure responsive design for various device sizes

### User Experience
- Implement intuitive form layout with clear instructions
- Add visual feedback for successful/unsuccessful operations
- Design clear validation error messages
- Create smooth navigation flow between steps

### Form Design
- Design phone number input with appropriate placeholder and formatting
- Create file upload control with clear file type restrictions
- Add validation state styling (invalid/valid indicators)
- Implement CSRF protection

### Implementation Reference

Main page template:
```html
{{define "title"}}Upload Resume - Profile{{end}}

{{define "page:main"}}
<main class="container">
    <article>
        <header>
            <h1>Welcome to Talent Rodeo</h1>
        </header>

        <h2>Let's start with your resume</h2>
        <p>
            Upload your resume and provide your phone number. We'll analyze your experience
            and have a quick chat to understand your preferences better.
        </p>

        {{template "partial:resume-form" .}}
    </article>
</main>
{{end}}
```

Form template:
```html
{{define "partial:resume-form"}}
<div id="resume-form">
    {{if .Form.Validator.HasErrors}}
    <article aria-label="Error message" role="alert"
        style="color: var(--pico-form-element-invalid-active-border-color);">
        Please correct the errors below and try again.
    </article>
    {{end}}

    <form method="post" action="/profile/resume/upload" enctype="multipart/form-data">
        <input type="hidden" name="csrf_token" value="{{ .CSRFToken }}">
        <div class="grid">
            <label for="phone">
                Phone Number
                <input type="tel" id="phone" name="phone" required placeholder="+1 (555) 555-5555"
                    value="{{.Form.Phone}}" {{with .Form.Validator.FieldErrors.phone}} aria-invalid="true"
                    aria-describedby="phone-error" {{end}}>
                {{with .Form.Validator.FieldErrors.phone}}
                <small id="phone-error" role="alert">{{.}}</small>
                {{end}}
            </label>

            <label for="resume">
                Resume (PDF or DOCX)
                <input type="file" id="resume" name="resume" required accept=".pdf,.docx"
                    aria-describedby="resume-help{{if .Form.Validator.FieldErrors.resume}} resume-error{{end}}" {{with
                    .Form.Validator.FieldErrors.resume}} aria-invalid="true" {{end}}>
                {{with .Form.Validator.FieldErrors.resume}}
                <small id="resume-error" role="alert">{{.}}</small>
                {{end}}
                <small id="resume-help">PDF or DOCX up to 10MB</small>
            </label>
        </div>

        <footer>
            <button type="submit">Continue</button>
        </footer>
    </form>
</div>
{{end}}
```

## Acceptance Criteria
- Resume upload form renders correctly with all required fields
- Form includes clear instructions and helpful placeholders
- File input accepts only PDF and DOCX files
- Phone input has appropriate validation and formatting guidance
- Form submission handles errors gracefully with clear user feedback
- UI is responsive across mobile, tablet, and desktop viewports
- Form includes CSRF protection
- UI maintains consistent styling with the rest of the application

## Dependencies
- HTML templating system
- CSS framework (Pico CSS or similar)
- Form validation utilities
- CSRF protection middleware
