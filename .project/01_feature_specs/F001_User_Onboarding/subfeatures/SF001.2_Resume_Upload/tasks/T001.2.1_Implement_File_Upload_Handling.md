# Task: Implement File Upload Handling

## Description
Implement the core file upload handling functionality for the Resume Upload feature. This task involves creating the server-side components that process the uploaded resume files, validate them, and store them securely.

## Implementation Details

### HTTP Handler and Route Configuration
- Create HTTP handlers for the resume upload functionality
- Configure routes for displaying the upload form (`GET /profile/resume/upload`) and processing the form submission (`POST /profile/resume/upload`)
- Implement handler for deleting existing resumes (`DELETE /profile/resume`)

### File Validation and Processing
- Implement file type validation to ensure only PDF and DOCX files are accepted
- Enforce file size limits (maximum 10MB)
- Create secure temporary file storage for processing
- Implement proper cleanup of temporary files

### Form Integration
- Create a form structure (`resumeUploadForm`) to hold and validate form data
- Implement form validation for phone number input using regex patterns
- Handle file upload errors with appropriate user feedback

File validation function:
```go
// isValidFileType checks if the given filename has an allowed extension (.pdf or .docx)
func isValidFileType(filename string) bool {
    ext := strings.ToLower(filepath.Ext(filename))
    return ext == ".pdf" || ext == ".docx"
}
```

- The upload form loads correctly and displays validation errors when appropriate
- File type validation correctly accepts only PDF and DOCX files
- File size validation limits uploads to 10MB
- Temporary file handling properly creates and cleans up files
- Form validation correctly validates the phone number format
- Appropriate error messages are displayed for all validation failures
