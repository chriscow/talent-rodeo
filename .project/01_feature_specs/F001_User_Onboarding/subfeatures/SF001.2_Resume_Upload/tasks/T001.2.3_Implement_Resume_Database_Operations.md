# Task: Implement Resume Database Operations

## Description
Design and implement the database operations required for storing and retrieving resume data. This includes updating user records with resume filenames, extracted text content, and phone number information, as well as maintaining the user's onboarding state.

## Implementation Details

### Database Schema Updates
- Review existing user table schema to ensure it has fields for:
  - `resume_filename` (nullable string)
  - `full_resume` (nullable text/blob for extracted content)
  - `phone` (nullable string)
  - `onboarding_step` (for tracking progress)

### Data Operations
- Implement function to update resume data in the database
- Implement function to update phone number
- Implement function to update onboarding step
- Create function to reset resume data (for deletion)

### Transaction Management
- Use proper context management for database operations
- Implement appropriate timeout handling
- Ensure data consistency during updates

### Implementation Reference

Resume update function:
```go
func (db *DB) UpdateFullResume(userID int, fileName, resume string) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    var query string
    var args []any

    if fileName == "" {
        query = `UPDATE users SET resume_filename=NULL, full_resume=NULL WHERE id = $1`
        args = []any{userID}
    } else {
        query = `UPDATE users SET resume_filename = $1, full_resume = $2 WHERE id = $3`
        args = []any{fileName, resume, userID}
    }

    _, err := db.ExecContext(ctx, query, args...)
    return err
}
```

Phone update function:
```go
func (db *DB) UpdateUserPhone(userID int, phone string) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    var phonePtr *string
    if phone != "" {
        phonePtr = &phone
    }

    query := `UPDATE users SET phone = $1 WHERE id = $2`
    _, err := db.ExecContext(ctx, query, phonePtr, userID)
    return err
}
```

Onboarding step update:
```go
func (db *DB) UpdateOnboardingStep(userID int, step onboarding.Step) error {
    ctx, cancel := context.WithTimeout(context.Background(), defaultTimeout)
    defer cancel()

    query := `UPDATE users SET onboarding_step = $1 WHERE id = $2`
    _, err := db.ExecContext(ctx, query, step, userID)
    return err
}
```

CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    first_name TEXT NOT NULL,
    last_name TEXT NOT NULL,
    phone TEXT,
    resume_filename TEXT,
    full_resume TEXT,
    onboarding_step TEXT NOT NULL DEFAULT 'initial',
    onboarding_started_at TIMESTAMP,
    onboarding_completed_at TIMESTAMP,
    onboarding_step_updated_at TIMESTAMP,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
