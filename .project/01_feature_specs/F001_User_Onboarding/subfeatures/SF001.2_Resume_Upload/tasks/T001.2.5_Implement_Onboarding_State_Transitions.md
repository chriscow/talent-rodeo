# Task: Implement Onboarding State Transitions

## Description
Implement the onboarding state management system that tracks user progress through the resume upload step and ensures proper state transitions. This includes updating the user's onboarding state upon successful resume upload and ensuring the flow to the next step.

## Implementation Details

### State Definition
- Review and use the onboarding state constants:
  - `StepInitial`: Starting state
  - `StepResumeUploaded`: State after successful resume upload
- Implement state transition logic for moving between steps

### State Management
- Update user's onboarding state on successful resume upload
- Reset state to initial when resume is deleted
- Implement authorization guards based on onboarding state
- Ensure proper flow between steps

### Flow Control
- Implement redirect logic based on onboarding state
- Implement protection against accessing steps out of order
- Ensure users can only access appropriate pages based on their state

### Implementation Reference

Onboarding state constants:
```go
// Step represents the current step in the user onboarding process
type Step string

const (
    // StepInitial is the starting state
    StepInitial Step = "initial"

    // StepResumeUploaded indicates the resume has been uploaded and processed
    StepResumeUploaded Step = "resume_uploaded"

    // StepPhoneCallScheduled indicates we've scheduled the phone call
    StepPhoneCallScheduled Step = "phone_call_scheduled"
    
    // Additional states...
)
```

State transition in handlers:
```go
// After successful resume upload
if err := app.db.UpdateOnboardingStep(user.ID, onboarding.StepResumeUploaded); err != nil {
    form.Validator.AddFieldError("resume", "Failed to update onboarding state. Please try again.")
    if err := response.NamedTemplate(w, http.StatusUnprocessableEntity, data, "partial:resume-form", "partials/resume-form.html"); err != nil {
        app.serverError(w, r, fmt.Errorf("failed to render form with error: %w", err))
    }
    return
}

// On resume deletion
if err := app.db.UpdateOnboardingStep(user.ID, onboarding.StepInitial); err != nil {
    app.serverError(w, r, fmt.Errorf("failed to update onboarding state: %w", err))
    return
}
```

## Acceptance Criteria
- User onboarding state updates correctly after successful resume upload
- State resets appropriately when resume is deleted
- Users are properly redirected based on their current onboarding state
- Users cannot access pages for steps they haven't reached yet
- Onboarding flow proceeds logically from resume upload to phone call scheduling
- Failed operations don't advance the onboarding state

## Dependencies
- Onboarding state definition system
- Database operations for state updates
- User authentication and context
