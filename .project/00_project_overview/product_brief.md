# Talent Rodeo Product Brief

## Core Concept
Talent Rodeo is an AI-powered job matching platform designed to help job seekers find opportunities aligned with their skills, experience, and preferences through intelligent conversation and data-driven matching.

## Product Vision
To create an intelligent recruitment platform that understands candidates beyond their resumes, builds lasting relationships through regular engagement, and makes precise matches between talent and opportunities.

## Target Users
### Job Seekers
- Professionals actively seeking new opportunities
- Passive candidates open to compelling opportunities
- Career changers looking for guidance and connections
- Recent graduates entering the workforce

## Key Features

### User Onboarding & Profile Creation
- LinkedIn OAuth integration for seamless authentication
- Resume upload capability (PDF, DOCX formats)
- Phone verification for future interactions
- Profile creation from LinkedIn and resume data

### Initial Assessment Process
- Automated outbound calling for initial assessment
- Structured conversation to gather information about skills and preferences
- Information extraction and analysis
- Privacy-first approach: No recordings kept, only summarized and derived transcriptions

### Job Search & Matching
- Integration with LinkedIn job listings via ScrapingDog
- Skill-based search capabilities
- Preference filtering for compensation, location, and work arrangement
- Match quality assessment performed internally
- Search result storage in user dashboard

### Business Model
- One-week free trial for all users
- All trial and paid users receive the same service level
- Paid subscription required to continue after trial period

## Success Metrics
- User acquisition: 500+ active users in first 3 months
- Job match quality: 70%+ user satisfaction
- Retention: 60%+ monthly active user retention

## Future Features
These features are planned for future releases and are not part of the initial product:

- Employer/Recruiter access
- Document customization (resume optimization, cover letter generation)
- Tiered service levels with different feature sets
- Enhanced profile visibility to recruiters
